# Карта экранов

## Маршруты

| Путь                    | Экран                                                       | Каркас           | Этап                                      | Статус   |
| ----------------------- | ----------------------------------------------------------- | ---------------- | ----------------------------------------- | -------- |
| `/`                     | Лендинг: что такое Ketner AI, кнопки «Начать чат» и «Войти» | StandaloneLayout | 1                                         | Готов    |
| `/chat`                 | Чат: пустое состояние с примерами, лента и композер         | AppShell         | 1 (каркас), 2 (лента и стриминг)          | Готов    |
| `/chat/:conversationId` | Тот же экран с загруженным диалогом                         | AppShell         | 2                                         | Готов    |
| `/login`                | Вход: email/пароль, кнопки Google и GitHub                  | StandaloneLayout | 1 (разметка), 3 (логика)                  | Каркас   |
| `/signup`               | Регистрация: имя, email, пароль, кнопки Google и GitHub     | StandaloneLayout | 1 (разметка), 3 (логика)                  | Каркас   |
| `/pricing`              | Тарифы Free, Plus, Pro и сравнение возможностей             | StandaloneLayout | 1 (витрина), 4 (подписка)                 | Готов    |
| `/checkout/:planId`     | Оформление подписки: форма карты                            | StandaloneLayout | 1 (разметка), 4 (логика)                  | Каркас   |
| `/settings`             | Настройки: аккаунт, внешний вид, подписка, выход            | AppShell         | 1 (внешний вид), 3-4 (аккаунт и подписка) | Частично |
| `/onboarding`           | Пустое состояние нового пользователя с примерами запросов   | AppShell         | 1                                         | Готов    |
| любой другой            | 404                                                         | StandaloneLayout | 1                                         | Готов    |

## Переходы

```
        ┌──────────────────────────────┐
        │  /  лендинг                  │
        └───────┬──────────────┬───────┘
                │ «Начать чат» │ «Войти»
                ▼              ▼
        ┌───────────────┐  ┌──────────────┐
        │  /chat        │  │  /login      │
        │  AppShell     │◄─┤  /signup     │
        └───┬───────┬───┘  └──────┬───────┘
            │       │             │ «Уже есть аккаунт»
            │       │             ▼
            │       │        (перелинковка /login ↔ /signup)
            │       │
            │       └──► /onboarding      пустое состояние с примерами
            │
            ├──► /settings                сайдбар → «Настройки»
            │        ├──► /login           аккаунт: «Войти»
            │        └──► /pricing         подписка: «Улучшить план»
            │
            └──► /pricing                 сайдбар → «Улучшить план»
                     └──► /checkout/plus   «Выбрать план»
                          или /checkout/pro
```

Из любого места доступны: переключатель темы (шапка, сайдбар, настройки) и переключатель языка RU/EN (сайдбар, настройки).

Новый чат не пишет на сервер: диалог создаётся при отправке первого сообщения, после чего адрес меняется с `/chat` на `/chat/:conversationId`. Так же работает и правка сообщения — она переписывает историю, а не создаёт новый диалог.

### Настройки остаются одностраничником

Разделов пока четыре (профиль, внешний вид, язык, подписка и выход), поэтому `/settings` — одна страница с секциями, без вложенного роутинга и бокового меню: меньше кода и меньше мест, где роутинг внутри роутинга может сломаться.

Подмаршруты (`/settings/profile`, `/settings/billing`, …) появятся, когда разделов станет шесть и больше или когда добавится тяжёлый раздел вроде истории платежей или экспорта данных. На контракты API это не влияет, так что решение не блокирует этапы 3-4.

## Состояния экранов

| Экран        | Пустое состояние                                         | Загрузка                                                     | Ошибка                                                                            |
| ------------ | -------------------------------------------------------- | ------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| Чат          | Приветствие и примеры запросов, подставляемые в композер | Skeleton ленты при открытии диалога, «думает…» при генерации | «Не удалось получить ответ» + «Повторить»; отдельный текст для удалённого диалога |
| Список чатов | «История пока пуста»                                     | Skeleton-строки диалогов                                     | «Не удалось загрузить историю» + «Повторить»                                      |
| Тарифы       | —                                                        | —                                                            | Неизвестный тариф на `/checkout/:planId` → экран «Страница не найдена» (этап 1)   |
| Оформление   | —                                                        | Индикатор на кнопке (этап 4)                                 | Отклонённая карта (этап 4)                                                        |

Общая страховка от ошибок рендера — `RouteErrorPage`: перехватывает сбой маршрута, пишет деталь в консоль и предлагает перезагрузить страницу.

## Заглушки и куда они ведут

| Элемент                | Где               | Сейчас                                 | Появится на этапе |
| ---------------------- | ----------------- | -------------------------------------- | ----------------- |
| «Поделиться»           | шапка чата        | поясняет, что функция в разработке     | 5                 |
| «Прикрепить файл»      | композер          | то же                                  | 5                 |
| Кнопки Google и GitHub | вход, регистрация | помечены как заглушки, обработчика нет | 3                 |
| «Выйти из аккаунта»    | настройки         | поясняет про демо-режим                | 3                 |
| «Оформить подписку»    | оформление        | показывает предупреждение демо-режима  | 4                 |

## Что ещё появится на этих экранах

- **Чат:** проверка лимитов плана перед отправкой (этап 4), вложения и «Поделиться» (этап 5).
- **Сайдбар:** профиль пользователя вместо «Гость» и выход из аккаунта (этап 3).
- **Вход:** валидация полей, мок-сессия, OAuth-заглушка с мгновенным входом.
- **Оформление:** маски ввода карты, статус подписки, экран «Подписка оформлена».
