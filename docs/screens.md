# Карта страниц

Маршруты — `apps/web/src/router/routes.tsx`. Каждая страница грузится отдельным чанком. Мета-теги, canonical и статус ответа для публичных страниц выставляет сервер (`apps/mock-api/src/seo/pages.ts`): несуществующие адреса отвечают 404.

## Публичные страницы (без сайдбара)

| Путь                                   | Страница                                                                                          |
| -------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `/`                                    | Лендинг: демо роутера, модели с лимитами, калькулятор экономии, тарифы, FAQ                       |
| `/pricing`                             | Тарифы Free, Plus, Pro, Ultra и как работают лимиты                                               |
| `/login`, `/signup`                    | Вход и регистрация: почта и пароль, Google, GitHub                                                |
| `/signup/verify`, `/login/verify`      | Второй шаг регистрации и входа: 6-значный код из письма, почта замаскирована, повтор через минуту |
| `/checkout/:planId`                    | Оплата тарифа: криптовалюта (Trybit) или Telegram Stars                                           |
| `/checkout/success`                    | Оплата прошла (цель «Покупка» Google Ads)                                                         |
| `/docs`, `/docs/plans/:planId`         | Справка для пользователей                                                                         |
| `/docs/api`                            | Справка по API (`/v1`) и ключи                                                                    |
| `/privacy`, `/terms`, `/payment-terms` | Политика конфиденциальности, пользовательское соглашение, условия оплаты и возврата               |
| `/contacts`                            | Контакты, известные проблемы и форма обратной связи с темой обращения                             |
| `/about`                               | О проекте: кто делает, какую задачу решает, этап, даты, планы                                     |
| `/models`                              | Модели: разработчик, настоящая модель за Ketner Mini и Ketner Pro, лимиты, запасные               |
| `/status`                              | Статус компонентов (`GET /api/status`), известные проблемы, история сбоев                         |
| `/changelog`                           | Журнал обновлений, известные ограничения и планы отдельно от вышедшего                            |
| `/tg`                                  | Кабинет в Telegram (мини-приложение), см. [telegram.md](telegram.md)                              |
| любой другой                           | 404                                                                                               |

## Приложение (с сайдбаром)

| Путь                        | Страница                                                                                                |
| --------------------------- | ------------------------------------------------------------------------------------------------------- |
| `/chat`, `/chat/:id`        | Чат. Новый диалог создаётся при первом сообщении, адрес меняется на `/chat/:id`                         |
| `/code`, `/code/:projectId` | Ketner Code: список проектов и импорт; файлы, редактор и агент ([code-workspace.md](code-workspace.md)) |
| `/images`                   | Генерация картинок                                                                                      |
| `/settings`                 | Профиль, тема и язык, подписка, GitHub, Telegram                                                        |
| `/api-docs`, `/developers`  | То же, что `/docs/api`, внутри приложения                                                               |
| `/onboarding`               | Первые шаги нового пользователя                                                                         |
| `/admin`                    | Админ-панель ([operations.md](operations.md#админ-панель))                                              |

Гость может писать в чат без входа (через бесплатную модель, с лимитом по IP). Ketner Code, картинки и оплата требуют входа.

## Основные переходы

```
/ ──► /chat (гость или после входа) ──► /chat/:id
│        ├─ сайдбар ──► /code, /images, /settings
│        └─ лимит или платная модель ──► окно «Улучшить план» ──► /pricing
├──► /login ⇄ /signup ──► /signup/verify (код из письма) ──► возврат на исходную страницу
└──► /pricing ──► /checkout/:planId ──► /checkout/success ──► /chat
```

## Состояния экранов

| Экран        | Пусто                          | Загрузка                  | Ошибка                                                              |
| ------------ | ------------------------------ | ------------------------- | ------------------------------------------------------------------- |
| Чат          | Приветствие и примеры запросов | Скелетон ленты, «думает…» | «Не удалось получить ответ» + «Повторить»; отдельно — диалог удалён |
| Список чатов | «История пока пуста»           | Скелетоны строк           | «Не удалось загрузить историю» + «Повторить»                        |
| Лимит        | —                              | —                         | Строка остатка под выбором модели, предупреждение с 80% расхода     |
| Оплата       | —                              | Индикатор на кнопке       | Счёт не выставлен → «Выставить счёт заново»                         |

Сбой рендера любой страницы перехватывает `RouteErrorPage`.
