# Модели, лимиты и цены подписок

Документ описывает, как устроены модели и экономика тарифов. Цены моделей: OpenRouter на 12.10.2026, $ за 1M токенов. Цены подписок: Plus $9, Pro $25, Ultra $49 (в долларах, как на сайте). Курс 95 ₽/$ нужен только для справочных сумм в рублях.

Все суммы задаются в одном месте: бюджеты и бонус за крипту — `services/entitlement.ts`, цены тарифов, пакетов и комиссии — `services/pricing.ts`, нормы лимитов — `services/daily-limits.ts`, цены моделей (OpenRouter и прямых API) — `ai/model-registry.ts`. Числа ниже посчитаны по этим файлам.

Модель, которая ответила, и причина выбора всегда видны (`selectedModel`, `routingReason`).

Невидимые пользователю изменения: кэш промпта перестал сбрасываться на каждом сообщении (разговор с длинной историей и проектом дешевле), а Claude, GPT и Gemini можно пустить напрямую через API вендора (по умолчанию выключено).

## 1. Как это работает

Основной канал — OpenRouter, один ключ `OPENROUTER_API_KEY` и один счёт. Прямые API вендоров — дополнительный путь, по умолчанию выключенный (раздел «Прямые API» ниже).

Путь запроса: `routes/chat.ts` → `AIGateway.stream` → выбор модели → провайдер `openrouter` (`RoutedProvider`: прямой API вендора, если задан его ключ, иначе и при сбое — OpenRouter).

1. **Бюджет пользователя.** Расход за скользящие 30 дней сравнивается с `costBudget` тарифа: 80% — экономный режим, 100% — только дешёвые модели, 125% — отказ. Расход, оплаченный кредитами пакетов, в бюджет тарифа не входит.
2. **Выбор модели.**
   - Режим Auto: `AutoRouter.route` (правила ниже).
   - Явный выбор: права проверяются по запрошенной модели, потом применяются правила экономии. Скрытой подмены нет: в ответе приходит `selectedModel` с моделью, которая реально ответила, и `routingReason`.
3. **Лимит модели.** Недельный пул и его суточная доля (`services/daily-limits.ts`, `ai/model-limits.ts`). После лимита отвечает запасная модель из `fallbackModelId`.
4. **Квота премиум-запросов.** Модели классов `strong` и `top` расходуют `premiumBudget` тарифа (при оплате криптой — на 15% больше). Когда квота кончилась, тратятся кредиты пакетов (только при явном выборе модели), потом отвечает Ketner Pro.
5. **Глубина размышлений** (`reasoning` в запросе). Токены размышлений оплачиваются как выходные, поэтому глубина выбирается по сложности запроса, тарифу, бюджету и тому, что поддерживает модель.
6. **Потолок ответа.** Лимит тарифа, потолок модели, 4096 токенов в экономном режиме, 2048 при исчерпанном бюджете.
7. **Failover.** Цепочка запасных моделей из реестра, без повторов, только допустимых по бюджету. Предохранитель ведётся на каждую модель отдельно. HTTP 401 и 402 не перебирают цепочку: это ключ или баланс, не модель. У прямого API свой предохранитель: при его сбое тот же запрос (та же модель) уходит в OpenRouter.
8. **Учёт.** Берётся `usage.cost` от OpenRouter (он включает размышления и кэш); у прямых API цена считается по их прайсу из реестра (`direct.pricing`, запись в кэш Anthropic ×1.25). Запись идёт по реально ответившей модели, в `provider` — канал (`openrouter`, `anthropic`, `openai`, `google`).
9. **Метрики.** `GET /api/admin/metrics` → `models30d`: по каждой модели за 30 дней число запросов, средний вход и выход, доля кэшированных токенов, вердикт по кэшу (`working` / `not_working` / `no_data` / `not_expected`), средняя цена запроса и доли тарифов в расходе. В админке — таблица «Модели за 30 дней».

### Прямые API вендоров

Включаются переменными окружения (в `.env.example` и `render.yaml` с `sync: false`); без ключа путь выключен:

| Переменная          | Модели напрямую                                                                              | Реализация                                          |
| ------------------- | -------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| `ANTHROPIC_API_KEY` | Claude Opus 5.5, Sonnet 5.5, Haiku 5.5                                                       | `AnthropicProvider` (официальный SDK)               |
| `OPENAI_API_KEY`    | Ketner Mini (GPT-6 Luna), GPT-6.1 Sol, GPT-6 Astra, GPT-5.6 Sol / Terra / Luna Pro, Luna Pro | `OpenAICompatibleProvider`, `OPENAI_BASE_URL`       |
| `GOOGLE_API_KEY`    | Gemini 3.7 Flash, 3.8 Flash, 4 Argon                                                         | OpenAI-совместимый API Gemini, `GOOGLE_AI_BASE_URL` |

- Модель та же, что в OpenRouter (`direct.modelId` в реестре), подмены нет; ответ, потоки, вызовы инструментов, размышления и usage с кэшированными токенами приходят в том же виде.
- При ошибке прямого API до первого токена тот же запрос уходит в OpenRouter; после трёх ошибок предохранитель на 30 секунд отправляет модель только через OpenRouter. Если ответ уже начал приходить, второй ответ не дописывается (ошибка уходит в обычную цепочку запасных моделей).
- Цены прямых API — в реестре рядом с ценами OpenRouter (поле `direct`). Они равны прайсу вендора; выигрыш прямого пути — комиссия пополнения OpenRouter 5.5% на трафик этого вендора и независимость от одного ключа. Поправить или выключить прямой путь модели можно без деплоя: `PATCH /api/admin/models/:id` с `direct: {modelId, pricing}` или `direct: null`.
- Агент Ketner Code ходит напрямую только к OpenAI и Gemini; Claude в агенте идёт через OpenRouter (его блоки размышлений нельзя передать обратно в формате OpenAI).
- Серверные `fallbacks` Anthropic не включены: они подменили бы модель без ведома пользователя.

### Кэширование промптов

Кэш промпта (`cache_control`) раньше почти не срабатывал: контекст привязанного проекта подбирался под каждый вопрос и лежал в системном промпте, а окно истории сдвигалось на каждом ходу, поэтому префикс запроса менялся на каждом сообщении. Теперь:

- системный промпт от вопроса не зависит, а файлы проекта, подобранные под вопрос, идут в само сообщение пользователя;
- окно истории сдвигается шагом в 6 сообщений (последние 8–13), и пока оно стоит, история читается из кэша;
- точки кэша — по вендору (`ai/prompt-cache.ts`): Anthropic — явные (конец системного промпта, первое сообщение-якорь, предпоследнее сообщение); Gemini — одна явная точка при префиксе от 4096 токенов; OpenAI, xAI, DeepSeek, GLM, Kimi и Qwen кэшируют автоматически по префиксу от ≈ 1024 токенов.

Тест `ai/prompt-cache.test.ts` моделирует диалог с проектом из 20 ходов: из кэша Claude читается не меньше 60% входа. На живых данных вердикт по каждой модели — в `/api/admin/metrics` (`cacheStatus`, `cachedTokenSharePct`).

### Лимиты моделей: недельный пул

У каждой модели тарифа есть суточная норма (`DAILY_MODEL_LIMITS`). Норма — основа пула, а не потолок на сутки:

- **пул** = норма × 7 ответов за скользящие 7 дней, тратить можно неравномерно;
- **за скользящие сутки** — не больше 40% пула, но не меньше нормы: `max(норма, ⌊0.4 × пул⌋)`;
- запрос в режиме Max (Ultra) считается за 2;
- после лимита отвечает запасная модель, причина видна в `routingReason`; запрос, оплаченный кредитами пакета, лимитом не ограничен.

Старые тарифы `gpt-pro`, `claude-pro`, `gemini-pro` получают лимиты Pro. Нормы, пулы и суточные доли отдаются в `/api/meta` (`weeklyLimits`).

### Режим размышлений Pro и Ultra, кнопка Max

Модели Pro и Ultra работают с фиксированной глубиной размышлений, а не адаптивной: Claude Opus, Sonnet, GPT-6 Astra, GPT-5.6 Sol (и Gemini 4 Argon) — medium; Grok 4.7 и GPT-5.6 Terra — всегда xhigh (так и подписаны). На Ultra в шапке чата есть кнопка **Max**: она переводит первые пять моделей на xhigh (запрос дороже примерно в 2.4 раза) и считается за **2** в лимите модели; на xhigh-моделях Max ничего не меняет. На Pro кнопка видна с замком и открывает переход на Ultra; сервер сам проверяет тариф (`reasoningMode: 'max'` от Pro выполняется как обычный запрос). Режим действует и в чате, и в агенте Ketner Code. При расходе 80% бюджета глубина опускается до low, а премиум-модели заменяются рабочими.

Старые id (`claude-fable` и `claude-fable-5.1` → Opus 5.5, `claude-3.5-sonnet` → Sonnet 5.5, `gemini-pro`, `gpt-4o`, `nemotron` и др.) продолжают работать через `LEGACY_MODEL_ALIASES`. `gpt-6-astra` снова настоящая модель каталога.

Не вошли намеренно: Claude Fable 5.1 (убрана 12.10.2026: в 2.5 раза дороже Opus 5.5 при более низкой оценке AA), Kimi K3, Qwen3.8 Max, DeepSeek V4 Pro, Muse Spark, Nemotron 3 Ultra (хуже или дороже Ketner Pro и GLM-5.3).

### Правила Auto

| Условие                                                              | Модель      |
| -------------------------------------------------------------------- | ----------- |
| Бюджет исчерпан                                                      | Ketner Mini |
| Free                                                                 | Ketner Mini |
| Простой вопрос                                                       | Ketner Mini |
| Обычная задача; любая задача на Plus; бюджет на исходе (80%+)        | Ketner Pro  |
| Pro/Ultra: код, математика или логика средней сложности              | GLM-5.3     |
| Pro/Ultra: сложная задача по коду, математике или логике, есть квота | GPT-6.1 Sol |
| Pro/Ultra: сложная задача, квота израсходована                       | GLM-5.3     |

**Сложная задача** (`AutoRouter.isHard`): доказательство, теорема, олимпиадная задача; проектирование системы или архитектуры сервиса; распределённые транзакции и блокировки; race condition, deadlock, утечка памяти; оптимизация алгоритма или производительности, асимптотика; уязвимости, криптография, компиляторы; условие длиннее 3000 символов; запрос с привязанным проектом. Короткая реплика («продолжи», «а если n = 0?») наследует сложность предыдущего вопроса, поэтому задача не скачет между моделями. «Объясни», «сравни», «напиши функцию», «найди ошибку», вложенный файл — средняя сложность.

Auto никогда не тратит кредиты пакетов и не выбирает Claude Opus 5.5 и GPT-6 Astra (класс `top`): они только по явному выбору. После лимита GLM-5.3 отвечает Ketner Pro.

**Экономия квоты.** Средняя задача на GLM-5.3 стоит ≈ $0.019 из общего бюджета вместо ≈ $0.035 из премиум-квоты (GPT-6.1 Sol). Если, например, две трети запросов Auto по коду, математике и логике на Pro — средней сложности, Auto расходует на них на две трети меньше квоты, и она остаётся на явный выбор Opus и Sonnet. Реальную долю видно в `/api/admin/metrics` (запросы GLM-5.3 и GPT-6.1 Sol) и в `routingReason`.

## 3. Окупаемость при ценах $9 / $25 / $49

Допущения (`services/pricing.ts`): налог 6%; Telegram Stars — выплата $0.013 за звезду (`STARS_PAYOUT_USD`), цена в звёздах — цена тарифа по официальному курсу Telegram $0.01999 за звезду (`STARS_OFFICIAL_USD_PER_STAR`), то есть до нас доходит ≈ 65% её стоимости; крипта (Trybit) ≈ 98%; Stripe 3.9% + $0.30 с платежа; СБП ≈ 1% (рубли по курсу не ниже цены в долларах); пополнение OpenRouter +5.5% к расходу (на трафик прямых API этой комиссии нет, поэтому расчёт — оценка сверху). Free-тир обходится не дороже $3.01 на одного платящего (`FREE_TIER_SUBSIDY_USD`: конверсия 5%, средний расход Free $0.15; сейчас Free идёт на бесплатные эндпоинты, так что это верхняя оценка).

**Цена в звёздах — цена тарифа по официальному курсу Telegram.** Официальная справочная цена звёзд в Telegram — 1 000 ⭐ = $19.99 ($0.01999 за звезду), на Fragment и у перекупщиков они дешевле (≈ $0.014–0.019). Раньше цена в звёздах считалась по курсу $0.015 (Fragment или значение по умолчанию), и тариф в звёздах выходил дороже карты: Pro 1 670 ⭐ — $33.38 у Telegram и не меньше $31 у перекупщиков.

Для карты дополнительно — не ниже 15% цены на 100% бюджета.
- **Крипта с бонусом выгоднее звёзд для нас во всех тарифах**: бонус стоит $0.26 / $1.58 / $3.27 даже на пределе, а крипта приносит на $2.67 / $7.63 / $15.08 больше звёзд. Для пользователя цена одинаковая, а крипта даёт ещё +15% квоты.
- **Звёзды — самый дорогой канал для нас**: до нас доходит ≈ 65% цены. Если доля оплат звёздами станет большой, а Free-тир снова начнёт стоить денег (например, бесплатные эндпоинты OpenRouter закончатся), стоит вернуть долю Free-тира в минимум для звёзд (`planStarsWorstCaseCostUsd` в `services/margin.ts`) — цены станут 580 / 1 440 / 2 630 ⭐ — или предлагать вместо звёзд крипту с бонусом.
- **Пакеты не ухудшают худший случай**: их кредиты не входят в бюджет тарифа, а каждый пакет сам по себе в плюсе (3–10% цены через звёзды, 34–39% через крипту).
- **Прямые API только улучшают расчёт**: у трафика через ключ вендора нет комиссии пополнения OpenRouter 5.5%.

### Вывод

- **Цены $9 / $25 / $49 держатся, повышать их не нужно.** Худший случай при оплате картой и криптой — маржа 18–55% на 100% бюджета (с учётом Free-тира); в звёздах тариф стоит столько же и без доли Free-тира тоже не уходит в минус даже на пределе 125%.
- **Пользователь получил больше без роста месячного расхода**: недельный пул вместо суточного лимита, видимый остаток, пакеты поверх подписки и +15% квоты за оплату криптой. Месячные `costBudget` и `premiumBudget` не менялись, кроме бонуса, который окупается разницей комиссий.
- **Auto меньше тратит премиум-квоту**: средние задачи по коду, математике и логике идут на GLM-5.3, квота остаётся для сложных задач и явного выбора топ-моделей.
- **Plus — самый тесный тариф**: при оплате звёздами без доли Free-тира на пределе 125% он в плюсе на 18%, с верхней оценкой доли Free — в минусе. Дальше урезать бюджет Plus не стоит; если нужна маржа 30% в худшем случае при оплате картой, цена Plus должна быть $10–11.
- **«Безлимит» окупается**, пока он остаётся Fair Use: бюджет и стадии 80% / 100% / 125% не дают одному пользователю потратить больше, чем зарабатывает тариф. При подходе к потолку человек не получает отказ сразу: он переходит на дешёвые модели (до 125% бюджета).
- **Free-тир — самая дорогая статья.** При конверсии ниже 3% субсидия растёт с $3 до $5–10 на платящего и съедает 30–100% прибыли Plus. Следите за конверсией и средним расходом Free; если она ниже 3%, снижайте лимит Free (сейчас 10 сообщений в сутки и бюджет $0.30).

## 4. Риски и что проверить

- **Код не проверялся на живых API**: в среде разработки нет ключей OpenRouter, Anthropic, OpenAI и Google. Перед выкладкой отправьте по 1–2 запроса на каждую модель, включая запрос с `reasoning`, Opus с кэшем промпта и GLM-5.3. Если OpenRouter отвечает 400 на значение `reasoning`, шлюз повторит запрос без параметра и напишет предупреждение в лог. Тогда поправьте таблицу размышлений модели в `model-registry.ts`.
- **Кэш промпта проверен симуляцией, а не на трафике.** Через несколько дней после выкладки откройте `/api/admin/metrics`: у Claude, GPT и Gemini `cacheStatus` должен быть `working`, а доля кэшированных токенов на длинных диалогах — десятки процентов. Если `not_working`, смотрите, что меняет префикс запроса (`ai/prompt-cache.ts`, `ai/workspace-context.ts`).
- **Прямые API.** Включайте по одному ключу и сверяйте `provider` в учёте и цены в админке со счетом вендора. Цены прямых API в реестре равны прайсу вендора на 12.10.2026; при изменении прайса поправьте `direct.pricing` через админку или в реестре. id моделей у вендоров (`claude-opus-5-5`, `gpt-6.1-sol`, `gemini-3.7-flash` и др.) тоже стоит проверить на первом запросе.
- **GLM-5.3 и границы «сложной» задачи.** Правила `AutoRouter.isHard` — эвристика по ключевым словам и длине. Проверьте на своих диалогах долю ответов GLM-5.3 и GPT-6.1 Sol в Auto и дизлайки; при необходимости расширьте список признаков или поменяйте модель (`OPEN_FLAGSHIP_MODEL_ID`).
- **Единый ключ OpenRouter — по-прежнему главная точка отказа.** При нуле на балансе (HTTP 402) отключаются все платные модели, кроме идущих через прямые API. Нужны автопополнение или оповещение при остатке ниже порога.
- **Ketner Pro — это MiMo-V2.6-Pro от Xiaomi, GLM-5.3 — модель Z.ai.** Проверьте доступность провайдеров и политику хранения данных в настройках OpenRouter.
- **Качество оценивалось по Artificial Analysis Intelligence Index**, а он измеряет общий интеллект, а не русский язык и ваши задачи. Прогоните свои типовые запросы через Ketner Pro, GLM-5.3 и Mini до запуска.
- **Учёт расхода хранится в Postgres** (`ketner_docs`, пространство `usage`) вместе с кредитами пакетов и журналом платежей, поэтому бюджеты, недельные пулы и квоты переживают деплой. Без `DATABASE_URL` — только в файле `usage.json`, который на Render стирается при каждом деплое.
- **Ограничение частоты (RPM)** — только задержка 2 секунды, не отказ.
- **Единые цены.** Каталог сайта, бэкенд, Trybit и Stars берут цены из `services/pricing.ts` и `plans.ts` (совпадение проверяет тест). Тексты «безлимит» с сайта убраны.
- **Stripe Price ID.** Stripe не подключён к странице оплаты. Если его включат и в окружении будут `STRIPE_PRICE_PLUS|PRO|ULTRA`, Stripe возьмёт цену оттуда, а не из кода — проверьте, что там $9 / $25 / $49.
- **Сумма по СБП (890 / 2 490 / 4 890 ₽) зафиксирована в `pricing.ts`.** СБП убрана со страницы оплаты; если вернётся, а рубль подешевеет заметно ниже 99 ₽/$, пересчитайте её (тест не допускает суммы ниже цены в долларах по курсу 95).
- **Тексты тарифов в `routes/billing.ts`** обещают «контекст до 60 / 120 / 500 сообщений», а `ContextOptimizer` отправляет последние 8–13 сообщений плюс сводку. Это только текст, на расход влияет в меньшую сторону.

**Бюджет на платные картинки:** Pro $3, Ultra $6 за скользящие 30 дней (около четверти общего бюджета
тарифа). Лимит каждой платной модели = этот бюджет / 30 / цена картинки: одной моделью до лимита каждый
день бюджета хватает примерно на месяц. Когда он потрачен, отвечают модели Cloudflare. Весь расход на
картинки входит и в общий месячный бюджет тарифа вместе с чатом: при исчерпании остаётся только schnell,
на жёстком пределе (125%) генерация останавливается. Одновременно у пользователя идёт одна генерация.

**Стили.** Под полем описания — «Выбрать стиль»: таблетки в одну строку со стрелками (без стиля,
рисунок на доске, аниме, промо товара, кино, мультфильм, промо приложения, комикс, UGC, затем фото,
портрет, акварель, масло, 3D, цифровой арт, пиксель-арт, скетч, неон, минимализм). Клиент присылает только id стиля, а сервер
(`images/styles.ts`) дописывает к английскому переводу фиксированную подсказку уже после проверки
запроса, поэтому через стиль нельзя обойти модерацию. Неизвестный id — без стиля.

**Модерация обязательна.** Сначала локальный фильтр (явные запросы с несовершеннолетними и
сексуальным содержанием отклоняются сразу), потом классификатор Ketner Mini через OpenRouter возвращает
`{allowed, category, prompt_en}`. Если классификатор недоступен или ответил не JSON, запрос
отклоняется. В модель уходит английский перевод описания.

**Хранение.** На Render диск временный, поэтому картинки лежат в Postgres (таблица `generated_images`,
байты в `bytea`), не больше 300 последних на пользователя. Без базы — файлы в `IMAGES_DIR`
(по умолчанию `apps/mock-api/data/images`). Файлы отдаются по подписанным ссылкам
`/api/images/:id/file?exp&sig` (HMAC, 6 часов), чтобы `<img>` работал без заголовка авторизации.

**API:** `GET /api/images/capabilities`, `GET /api/images`, `POST /api/images/generate`
`{prompt, modelId, aspect}`, `DELETE /api/images/:id`. Все, кроме ссылки на файл, требуют входа.
Без `RUNWARE_API_KEY` платные модели не показываются.

**Что проверить после пополнения Runware:** по одной картинке каждой платной моделью (реальная цена
видна в учёте), и что Seedream 5.0 Flash и Nano Banana 2 принимают другие пропорции — тогда их можно
открыть в `images/models.ts`.
