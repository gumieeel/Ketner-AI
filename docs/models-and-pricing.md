# Модели, кредиты и цены пакетов

Документ описывает, как устроены модели, кредиты и экономика пакетов. Цены моделей: OpenRouter на 12.10.2026, $ за 1M токенов. Подписок больше нет (сняты с продажи 26.10.2026): кредиты покупаются пакетами $5 / $10 / $25 / $50 / $100, а каждый новый аккаунт получает один раз 200 пробных кредитов. Курс 95 ₽/$ нужен только для справочных сумм в рублях по прежним платежам.

Все суммы задаются в одном месте: пакеты, комиссии, выплата за звезду и стоимость пробных кредитов — `services/pricing.ts`, пробный грант и технические лимиты уровней — `services/entitlement.ts`, остаток, списание и отчёт «сколько запросов осталось» — `services/credits.ts` (хранилище грантов — `store/credit-store.ts`), правила «хватает ли кредитов» — `services/credit-policy.ts`, маржа пакетов в худшем случае — `services/margin.ts`, технические лимиты — `services/fair-use.ts`, `services/code-limits.ts`, `images/models.ts`, цены моделей (OpenRouter и прямых API) — `ai/model-registry.ts`. Числа ниже посчитаны по этим файлам, а сайту их отдаёт `apps/web/src/features/billing/plan-facts.json` (сверка — тест `services/plan-facts.test.ts`).

**Кто что видит.** Под выбором модели строка «Кредиты» показывает остаток, цену выбранной модели и дату, когда сгорит ближайший грант; когда не хватает на модель, предлагает купить пакет. **Auto тратит кредиты только на сложные задачи.** Для пользователя с купленными кредитами любой запрос по коду, математике или логике средней сложности отвечает открытая модель GLM-5.3 (≈ 19 кредитов), а GPT-6.1 Sol (≈ 35) остаётся для доказательств, проектирования систем, отладки гонок и утечек, длинных условий и работы с привязанным проектом, и только если кредитов хватает на его запрос. На пробных кредитах Auto отвечает Ketner Mini, а его на уровне Free заменяет бесплатный эндпоинт, поэтому пробные кредиты уходят только на явный выбор платной модели. Модель, которая ответила, и причина выбора всегда видны (`selectedModel`, `routingReason`).

Невидимые пользователю изменения: кэш промпта перестал сбрасываться на каждом сообщении (разговор с длинной историей и проектом дешевле), а Claude, GPT и Gemini можно пустить напрямую через API вендора (по умолчанию выключено).

## 1. Как это работает

Основной канал — OpenRouter, один ключ `OPENROUTER_API_KEY` и один счёт. Прямые API вендоров — дополнительный путь, по умолчанию выключенный (раздел «Прямые API» ниже).

Путь запроса: `routes/chat.ts` → `AIGateway.stream` → выбор модели → провайдер `openrouter` (`RoutedProvider`: прямой API вендора, если задан его ключ, иначе и при сбое — OpenRouter).

1. **Кредиты.** Шлюз берёт остаток пользователя (`CreditService.balance`: новому аккаунту он при необходимости выдаёт пробный грант, один раз) и стадию: `normal` — есть хотя бы 1 кредит ($0.001), `exhausted` — кредитов нет. Гости кредитов не имеют: они всегда на бесплатной модели.
2. **Выбор модели.**
   - Режим Auto: `AutoRouter.route` (правила ниже). Сильная модель выбирается, только если остатка хватает на её типичный запрос; когда кредиты кончились, Auto выбирает бесплатную модель.
   - Явный выбор: открыта любая модель каталога (права по уровню больше не проверяются: `requiredPlan` у всех моделей пуст), поэтому проверяется только, хватает ли кредитов на её типичный запрос (`credit-policy.ts` → `pickAffordable`). Если не хватает, отвечает первая модель, на которую хватает: запасные из её цепочки (они дешевле), потом Ketner Mini, и последней — бесплатная. Скрытой подмены нет: в ответе приходит `selectedModel` с моделью, которая реально ответила, и `routingReason` («Not enough credits for X: Y answers instead» или «Credits used up: Y answers instead of X»).
   - Уровень Free (нет купленных кредитов): вместо платного Ketner Mini отвечает бесплатный эндпоинт (раздел «Бесплатные эндпоинты»); остальные модели тратят пробные кредиты.
   - Сравнение ответов (`strictModel`): подмена запрещена, при нехватке кредитов колонка получает ошибку `insufficient_credits`.
3. **Технические лимиты (Fair Use).** Запросы в минуту, час и сутки, токены в час и сутки, параллельные запросы — защита от злоупотреблений (раздел «Технические лимиты»). На расход кредитов они не влияют и не зависят от модели.
4. **Глубина размышлений** (`reasoning` в запросе). Токены размышлений оплачиваются как выходные, поэтому глубина выбирается по сложности запроса, уровню и тому, что поддерживает модель. Когда кредиты кончились, глубина не выше low.
5. **Потолок ответа.** Лимит уровня, потолок модели, 2048 токенов для простого вопроса и когда кредиты кончились.
6. **Failover.** Цепочка запасных моделей из реестра, без повторов. Платная запасная модель допустима, только если на неё хватает кредитов (`isAffordableFallback`), бесплатная — всегда. Предохранитель ведётся на каждую модель отдельно. HTTP 401 и 402 не перебирают цепочку: это ключ или баланс, не модель. У прямого API свой предохранитель: при его сбое тот же запрос (та же модель) уходит в OpenRouter.
7. **Учёт и списание.** Берётся `usage.cost` от OpenRouter (он включает размышления и кэш); у прямых API цена считается по их прайсу из реестра (`direct.pricing`, запись в кэш Anthropic ×1.25). После ответа с пользователя списывается его фактическая цена (`CreditService.charge`, не больше остатка); бесплатные модели, ответы из кэша и шаблонные ответы ничего не списывают. Запись идёт по реально ответившей модели, в `provider` — канал (`openrouter`, `anthropic`, `openai`, `google`).
8. **Метрики.** `GET /api/admin/metrics` → `models30d`: по каждой модели за 30 дней число запросов, средний вход и выход, доля кэшированных токенов, вердикт по кэшу (`working` / `not_working` / `no_data` / `not_expected`), средняя цена запроса и доли уровней в расходе. В админке — таблица «Модели за 30 дней».

### Кредиты

Кредиты лежат грантами (`store/credit-store.ts`, пространство `credit_grants`). Грант — это сумма, срок и источник: `pack` (купленный пакет, 365 дней), `bonus` (бонус +15% за крипту на тот же срок), `free` (пробные 200 кредитов, 30 дней, пометка `trial`), `plan` (кредиты прежней подписки), `auto` (уровень без платежа: VIP, выданный администратором), `admin` (ручная выдача).

- **Списание.** Первыми тратятся гранты, которые сгорают раньше, поэтому пробные кредиты уходят раньше купленных. Идентификаторы грантов идемпотентны (пакет — `${payment.id}`, бонус — `${payment.id}:bonus`, пробный — `trial:${userId}`), поэтому повторная доставка вебхука кредиты не удваивает.
- **Покупка пакета.** `BillingService.grantPack` → `CreditService.grantForPack`: грант `pack` на `CREDIT_PACK_VALID_DAYS` = 365 дней; криптой к нему добавляется отдельный грант `:bonus` на 15% (округление до 5 кредитов). Подписка пользователя не меняется, платёж попадает в журнал с `packId`, в Telegram приходит чек.
- **Пробные кредиты.** `CreditService.balance` выдаёт 200 кредитов (`TRIAL_CREDITS`, `TRIAL_DAYS` = 30) один раз на аккаунт при первом обращении. Повторно они не выдаются, даже если потрачены или сгорели. Для нас они стоят не больше $0.21 на зарегистрированного (`TRIAL_COST_USD`); окупаемость — в разделе 3.
- **Уровень доступа.** В базе у пользователя остаётся `free`. Пока есть неистраченные купленные кредиты, `applyPurchasedAccess` (`services/user-plan.ts`, `CreditService.hasPurchased`) возвращает вычисляемый уровень `credits`: 4 000 сообщений в сутки, API-ключи, команды агента, все модели картинок. Купленные кредиты кончились — пользователь снова на уровне Free. Значение `credits` в базе не хранится.
- **Прежние подписчики.** Действующая подписка (Plus / Pro / Ultra, `gpt-pro` / `claude-pro` / `gemini-pro`) работает до конца оплаченного срока: кредиты и лимиты по-прежнему даёт её тариф. Выставить новую подписку или продление нельзя (410 `subscriptions_discontinued`), автопродление звёздами можно только выключить (`PUT /api/telegram/app/auto-renew` с `enabled: false`).
- **Возврат.** Заявкой в течение 14 дней после оплаты и только если из кредитов этого пакета ничего не потрачено (`ledger.credits.spentFromPayment`); пробные кредиты возврат не блокируют. Решение принимает администратор: звёзды возвращает Telegram, криптовалюту администратор переводит вручную.
- **Ручная выдача.** `POST /api/admin/users/:id/credits` `{credits (1…1 000 000), days (1…365, по умолчанию 30), note}`; в списке и карточке пользователя в админке — остаток, куплено, расход за месяц, ближайшее сгорание и гранты.
- **API.** `GET /api/packs` — публичный каталог пакетов; `GET /api/usage/credits[?mode=max]` — остаток, пробные кредиты, стадия, цена каждой модели в кредитах, гранты и дата сгорания (для интерфейса); `GET /v1/usage` и поле `ketner.credits` в ответах `/v1` — то же для агентского API (`docs/agent-api.md`); `/api/meta` отдаёт цену запроса каждой модели (`requestCredits`, `requestCreditsMax`, `free`) и технические лимиты обоих уровней.

| `ANTHROPIC_API_KEY` | Claude Opus 5.5, Sonnet 5.5, Haiku 5.5                                                       | `AnthropicProvider` (официальный SDK)               |
| `OPENAI_API_KEY`    | Ketner Mini (GPT-6 Luna), GPT-6.1 Sol, GPT-6 Astra, GPT-5.6 Sol / Terra / Luna Pro, Luna Pro | `OpenAICompatibleProvider`, `OPENAI_BASE_URL`       |
| `GOOGLE_API_KEY`    | Gemini 3.7 Flash, 3.8 Flash, 4 Argon                                                         | OpenAI-совместимый API Gemini, `GOOGLE_AI_BASE_URL` |

- Модель та же, что в OpenRouter (`direct.modelId` в реестре), подмены нет; ответ, потоки, вызовы инструментов, размышления и usage с кэшированными токенами приходят в том же виде.
- При ошибке прямого API до первого токена тот же запрос уходит в OpenRouter; после трёх ошибок предохранитель на 30 секунд отправляет модель только через OpenRouter. Если ответ уже начал приходить, второй ответ не дописывается (ошибка уходит в обычную цепочку запасных моделей).
- Цены прямых API — в реестре рядом с ценами OpenRouter (поле `direct`). Они равны прайсу вендора; выигрыш прямого пути — комиссия пополнения OpenRouter 5.5% на трафик этого вендора и независимость от одного ключа. Поправить или выключить прямой путь модели можно без деплоя: `PATCH /api/admin/models/:id` с `direct: {modelId, pricing}` или `direct: null`.
- Агент Ketner Code ходит напрямую только к OpenAI и Gemini; Claude в агенте идёт через OpenRouter (его блоки размышлений нельзя передать обратно в формате OpenAI).
- Серверные `fallbacks` Anthropic не включены: они подменили бы модель без ведома пользователя.

### Кэширование промптов

Кэш промпта (`cache_control`) раньше почти не срабатывал: контекст привязанного проекта подбирался под каждый вопрос и лежал в системном промпте, а окно истории сдвигалось на каждом ходу, поэтому префикс запроса менялся на каждом сообщении. Теперь:

- системный промпт от вопроса не зависит, а файлы проекта, подобранные под вопрос, идут в само сообщение пользователя;
- окно истории сдвигается шагом в 6 сообщений (последние 8–13), и пока оно стоит, история читается из кэша;
- точки кэша — по вендору (`ai/prompt-cache.ts`): Anthropic — явные (конец системного промпта, первое сообщение-якорь, предпоследнее сообщение); Gemini — одна явная точка при префиксе от 4096 токенов; OpenAI, xAI, DeepSeek, GLM, Kimi и Qwen кэшируют автоматически по префиксу от ≈ 1024 токенов.

Тест `ai/prompt-cache.test.ts` моделирует диалог с проектом из 20 ходов: из кэша Claude читается не меньше 60% входа. На живых данных вердикт по каждой модели — в `/api/admin/metrics` (`cacheStatus`, `cachedTokenSharePct`).

### Бесплатные эндпоинты (уровень Free и исчерпанные кредиты)

На уровне Free (нет купленных кредитов) Ketner Mini и Auto заменяет бесплатная `:free`-модель OpenRouter (`ai/plan-substitute.ts`); когда кредиты кончились совсем, в ту же бесплатную модель уходят все запросы (`services/credit-policy.ts`):

| Где               | Запрошено          | Отвечает                                 | OpenRouter                               |
| ----------------- | ------------------ | ---------------------------------------- | ---------------------------------------- |
| Чат               | Ketner Mini / Auto | Nemotron 3 Ultra (Free) `nemotron-ultra` | `nvidia/nemotron-3-ultra-550b-a55b:free` |
| Агент Ketner Code | Ketner Mini / Auto | North Mini Code (Free) `north-mini-code` | `cohere/north-mini-code:free`            |

Лимиты `:free` у OpenRouter общие на аккаунт: 20 запросов в минуту и 1 000 в день (при купленных кредитах от $10, иначе 50). Поэтому при отказе бесплатной модели (429, ошибка, пустой ответ) запрос уходит на платный Ketner Mini, если на него хватает кредитов, и расход пользователя без покупок не выходит за пробный грант в 200 кредитов (не больше $0.21 один раз на аккаунт). Пока пул не исчерпан, обычный ответ на Free стоит $0, поэтому пробные кредиты уходят в основном на явный выбор платной модели; картинка FLUX.1 schnell стоит меньше одного кредита. Гости (без аккаунта) работают на `nemotron-ultra`, без запасной модели. Ту же бесплатную модель получают покупатели, когда кредиты кончились, поэтому общий лимит OpenRouter делят гости, пользователи на пробных кредитах и покупатели без остатка: «кредиты не тратятся» не значит «без технических лимитов» (следите за долей 429 у `nemotron-ultra` и `north-mini-code`). Запросы Free уходят на бесплатные эндпоинты, где провайдер может логировать промпты: это нужно отразить в политике приватности. Laguna S 2.1 (free) не подключена: в каталоге у неё срок отключения 31.10.2026.

Служебная модель, которая в списке не показывается и работает только как запасная: `gpt-6-luna-pro` (`openai/gpt-6-luna-pro`, 0.10 / 0.50). Qwen3.8 Flash с 27.10.2026 выбирается и в списке; старый id `glm-5.3-flash` больше не перенаправляется на Ketner Mini, это отдельная модель.

**Добавлено 27.10.2026** (цены OpenRouter на эту дату): GLM-5.3 Flash (≈ 2 кредита за типичный запрос), Qwen3.8 Flash (≈ 2), GPT-6.1 Terra (≈ 18; вдвое дешевле GPT-5.6 Terra, размышления обязательны), Qwen3.8 Max (≈ 27), Kimi K3.1 Pro (≈ 35, как у Sol). GPT-5.6 Terra осталась в списке для тех, кто её уже выбрал.

Модель «Luna Decisions» в OpenRouter не найдена, вместо неё запасной для Sol стал `openai/gpt-6-luna-pro`. Варианты `:batch` в OpenRouter работают только через асинхронный Batch API (до 24 часов, без стриминга), поэтому в чат подключена обычная `google/gemini-3.7-flash`.

### Технические лимиты

Лимиты Fair Use защищают сервис от злоупотреблений и перегрузки, но не делят деньги: расход ограничивают только кредиты. Лимитов на отдельные модели и потолков расхода в день нет — дорогая модель просто быстрее съедает кредиты. Уровней два (числа в `services/entitlement.ts`, `services/code-limits.ts`, `images/models.ts`; сайту их отдаёт `apps/web/src/features/billing/plan-facts.json`, сверка — тест `services/plan-facts.test.ts`):

| Уровень                            | Сообщений/сутки | Запросов в минуту / час | Параллельных | Токенов в час / сутки | Потолок ответа | Запусков агента/сутки | Бюджет запуска агента | API-ключи |
| ---------------------------------- | --------------- | ----------------------- | ------------ | --------------------- | -------------- | --------------------- | --------------------- | --------- |
| Free (пробные или нулевой остаток) | 10              | 5 / 10                  | 1            | 50k / 150k            | 2048           | 10                    | $0.20                 | нет       |
| Credits (есть купленные кредиты)   | 4 000           | 80 / 600                | 8            | 4M / 20M              | 16384          | 120                   | $3.00                 | да        |

Бюджет запуска агента (`maxRunCostUsd`) — потолок себестоимости одного запуска на выбранной модели: один запрос пользователя превращается в десятки обращений к модели. Когда бюджет модели исчерпан, агент молча продолжает на модели дешевле (сначала рабочей, потом лёгкой), но не тратит больше остатка кредитов; когда кредиты кончились, агент работает на North Mini Code. Типичная задача агента стоит от ≈ $0.4 (Sonnet, GPT-5.6 Sol) до ≈ $0.75 (Opus), то есть 400–750 кредитов (см. `docs/code-workspace.md`). На пробных 200 кредитах такая задача не поместится целиком: агент остановится на нехватке кредитов или продолжит на бесплатной модели.

Проверки ответов другой моделью (ответ в чате, ревью кода, судья сравнения) считаются одним суточным лимитом: Free 2, Credits 80 (`services/review-policy.ts`). Деньги при этом списываются как обычно, по реальной цене проверки.

Прежние подписчики сохраняют свои технические лимиты (Plus, Pro, Ultra) до конца оплаченного срока; `gpt-pro`, `claude-pro`, `gemini-pro` получают лимиты Pro и 5 000 кредитов.

### Сравнение ответов

Кнопка **Сравнить** в шапке чата открыта всем: один вопрос уходит нескольким моделям (минимум 2). Пока нет купленных кредитов, можно сравнивать до 2 моделей, после первой покупки — до 4 (лимит зависит от ранга уровня: Free 2, Credits 4, прежние Plus 2 / Pro 3 / Ultra 4). Параллельных запросов у Free один, поэтому колонки сравнения идут по очереди. Каждая колонка стоит как обычный запрос и списывает кредиты по реальной цене: сравнение трёх моделей расходует втрое больше обычного ответа. Подмена моделей запрещена (флаг `strictModel` шлюза): если кредитов на модель не хватает, колонка отвечает ошибкой `insufficient_credits`, а не запасной моделью. Выбор лучшего ответа записывается (`compare_votes`), по нему считается, какие модели выбирают чаще.

### Режим размышлений, кнопка Max

Модели премиум-класса работают с фиксированной глубиной размышлений, а не адаптивной: Claude Opus, Sonnet, GPT-6 Astra, GPT-5.6 Sol (и Gemini 4 Argon) — medium; Grok 4.7 и GPT-5.6 Terra — всегда xhigh (так и подписаны). Кнопка **Max** в шапке чата открыта любому вошедшему пользователю: она переводит первые пять моделей на xhigh (запрос дороже примерно в 2.4 раза: кредиты тратятся во столько же раз быстрее); на xhigh-моделях Max ничего не меняет. Интерфейс показывает цену запроса в режиме Max (`GET /api/usage/credits?mode=max`). Режим действует и в чате, и в агенте Ketner Code. Когда кредиты кончились, отвечает бесплатная модель, и глубина не выше low.

Старые id (`claude-fable` и `claude-fable-5.1` → Opus 5.5, `claude-3.5-sonnet` → Sonnet 5.5, `gemini-pro`, `gpt-4o`, `nemotron` и др.) продолжают работать через `LEGACY_MODEL_ALIASES`. `gpt-6-astra` снова настоящая модель каталога.

Не вошли намеренно: Claude Fable 5.1 (убрана 12.10.2026: в 2.5 раза дороже Opus 5.5 при более низкой оценке AA), Kimi K3, Qwen3.8 Max, DeepSeek V4 Pro, Muse Spark, Nemotron 3 Ultra (хуже или дороже Ketner Pro и GLM-5.3).

**Сложная задача** (`AutoRouter.isHard`; её премиум-модели Auto отдаёт только при купленных кредитах): доказательство, теорема, олимпиадная задача; проектирование системы или архитектуры сервиса; распределённые транзакции и блокировки; race condition, deadlock, утечка памяти; оптимизация алгоритма или производительности, асимптотика; уязвимости, криптография, компиляторы; условие длиннее 3000 символов; запрос с привязанным проектом. Короткая реплика («продолжи», «а если n = 0?») наследует сложность предыдущего вопроса, поэтому задача не скачет между моделями. «Объясни», «сравни», «напиши функцию», «найди ошибку», вложенный файл — средняя сложность.

Auto не выбирает Claude Opus 5.5 и GPT-6 Astra (класс `top`): они только по явному выбору и списывают кредиты по реальной цене.

**Экономия кредитов.** Средняя задача на GLM-5.3 стоит ≈ 19 кредитов вместо ≈ 35 у GPT-6.1 Sol. Если, например, две трети запросов Auto по коду, математике и логике — средней сложности, Auto тратит на них на две трети меньше кредитов, и они остаются на явный выбор Opus и Sonnet. Реальную долю видно в `/api/admin/metrics` (запросы GLM-5.3 и GPT-6.1 Sol) и в `routingReason`.

Каталог пакетов — единственный способ платить. Цена тысячи кредитов падает с размером пакета, скидка считается к ставке пакета $5 ($2.17 за тысячу):

| ----- | -------- | ----------- | ------ | -------- | ---------------------- |
| $5    | 2 300    | $2.17       | —      | 260 ⭐   | +345                   |
| $10   | 4 700    | $2.13       | −2%    | 510 ⭐   | +705                   |

Один кредит — $0.001 реальной стоимости запроса, а цена тысячи кредитов $1.74–2.17, то есть **кредиты продаются в 1.7–2.2 раза дороже их себестоимости**; остальное уходит на налог, комиссию канала, комиссию OpenRouter за пополнение (5.5% расхода) и прибыль. Пакеты $5–$50 дают понятную скидку; пакет $100 со скидкой 20% — решение владельца (поощрить крупные покупки), в звёздах он почти на нуле, зато в остальных каналах остаётся в плюсе.

**Бонус за оплату криптой** (`CRYPTO_PACK_BONUS_RATE` = 15%, `packCryptoBonusCredits`). Пакет, оплаченный через Trybit, получает отдельный грант бонусных кредитов на тот же срок. Комиссию Trybit платит сервис, а не покупатель: он вносит ровно цену пакета (раньше комиссия ложилась на покупателя). Бонус окупается разницей комиссий: со звёзд до нас доходит $0.013 из официальных $0.01999 за звезду (≈ 65%), с криптой ≈ 98% цены. На странице оплаты бонус объяснён в цифрах.

**Цена в звёздах** — цена пакета по официальному курсу Telegram (1 000 ⭐ = $19.99, `STARS_OFFICIAL_USD_PER_STAR`), округление вверх до 10 звёзд (`packListStars`): 260 / 510 / 1 260 / 2 510 / 5 010 ⭐, то есть как картой с точностью до округления. Рыночный курс Fragment показывается только для сравнения. Минимум без убытка (`packMinStars`) — сколько звёзд нужно, чтобы выручка после налога покрыла худший расход пакета; при официальном курсе он ниже цены и не срабатывает (у пакета $100 запас всего 40 звёзд: 4 970 против 5 010 ⭐), он защищает, только если в `STARS_USD_RATE` задан слишком дорогой курс.

**Уровни и прежние подписчики.** Подписки Plus $9 / Pro $25 / Ultra $49 и `gpt-pro` / `claude-pro` / `gemini-pro` (1199 ₽ ≈ $12.62) больше не продаются; действующие доживают срок, цены хранятся в `services/pricing.ts` (`PLAN_PRICE_USD`, `LEGACY_PRICE_USD`) только для журнала платежей и возвратов. Каталог сайта цен подписок не хранит: пакеты он берёт из `plan-facts.json`, это проверяет `services/pricing.test.ts`.

**Пробные кредиты.** 200 кредитов один раз на аккаунт, срок 30 дней (`TRIAL_CREDITS`, `TRIAL_DAYS`). Стоимость для нас не выше $0.21 на зарегистрированного (200 кредитов × 1.055, `TRIAL_COST_USD`), если потрачены целиком. Это 1 запрос к GPT-6 Astra, ≈ 40 к Ketner Pro или ≈ 111 к Ketner Mini (`trial.examples` в `plan-facts.json`).

## 3. Окупаемость пакетов

Допущения (`services/pricing.ts`, `services/margin.ts`): налог 6%; Telegram Stars — выплата $0.013 за звезду (`STARS_PAYOUT_USD`), цена в звёздах — цена пакета по официальному курсу Telegram $0.01999 за звезду, то есть до нас доходит ≈ 65% её стоимости; крипта (Trybit) ≈ 98% цены, комиссию несёт сервис, покупатель платит ровно цену пакета; карта (Stripe) 3.9% + $0.30 с платежа (оплата картой в интерфейсе сейчас выключена, расчёт для сравнения); пополнение OpenRouter +5.5% к расходу (на трафик прямых API этой комиссии нет, поэтому расчёт — оценка сверху). Субсидии Free-тира больше нет: вместо неё есть разовая стоимость пробных кредитов (≤ $0.21 на зарегистрированного).

**Маржа в худшем случае** — покупатель тратит все кредиты пакета (и бонус за крипту, если платил ей) до последнего. Больше потратить нельзя: дальше отвечает бесплатная модель. Расход = кредиты × 1.055. Прибыль и доля от цены пакета (`packProfitUsd`, звёзды — по ценам в звёздах из таблицы выше):

| Пакет | Звёзды          | Крипта с бонусом | Карта (Stripe) |
| ----- | --------------- | ---------------- | -------------- |
| $5    | +$0.75 (15%)    | +$1.82 (36%)     | +$1.78 (36%)   |
| $10   | +$1.27 (13%)    | +$3.51 (35%)     | +$3.75 (38%)   |
| $25   | +$2.84 (11%)    | +$8.59 (34%)     | +$9.67 (39%)   |
| $50   | +$5.04 (10%)    | +$16.58 (33%)    | +$19.11 (38%)  |
| $100  | **+$0.56 (1%)** | +$22.36 (22%)    | +$29.14 (29%)  |

Что из этого следует:

- **Минуса нет ни в одном канале и ни в одном пакете**, включая худший случай. Самое тонкое место — пакет $100 в звёздах: +$0.56, то есть ≈ 1% при полной трате кредитов и бонуса. Это осознанное решение владельца (скидка 20% на крупный пакет «даже если будет минус в звёздах»). Прибыль в этом канале появляется только за счёт кредитов, которые не потратят до срока (365 дней); если Telegram снизит выплату за звезду, пакет $100 в звёздах уйдёт в минус. Следите за `STARS_PAYOUT_USD` и при необходимости поднимите цену в звёздах или уберите скидку для канала.
- **Остаток, который не потратили за 365 дней, сгорает** и становится чистой прибылью. Расчёт его не учитывает (считаем, что всё потрачено), поэтому реальная маржа выше.
- **Звёзды — самый дорогой канал**: до нас доходит ≈ 65% цены. Крипта с бонусом выгоднее звёзд в каждом пакете: бонус стоит нам $0.36 / $0.74 / $1.88 / $3.84 / $9.10 (с комиссией OpenRouter), и всё равно крипта приносит прибыли больше звёзд на $1.07 / $2.24 / $5.75 / $11.54 / $21.80. Для пользователя цена одинаковая, а крипта даёт ещё бонусные кредиты.
- **Прямые API только улучшают расчёт**: у трафика через ключ вендора нет комиссии пополнения OpenRouter 5.5%.

**Окупаемость пробных кредитов.** Пробный грант — 200 кредитов, до $0.21 на каждого зарегистрированного, если потрачены целиком. Он окупается, если достаточная доля зарегистрированных покупает пакет (`trialBreakEvenConversion` = стоимость пробного гранта / прибыль с пакета):

| Пакет | Звёзды | Крипта | Карта |
| ----- | ------ | ------ | ----- |
| $5    | 28.1%  | 11.6%  | 11.9% |
| $10   | 16.6%  | 6.0%   | 5.6%  |
| $25   | 7.4%   | 2.5%   | 2.2%  |
| $50   | 4.2%   | 1.3%   | 1.1%  |
| $100  | 37.7%  | 0.9%   | 0.7%  |

Читать так: если средний покупатель берёт пакет $10 и платит картой или криптой, пробные кредиты окупаются, когда покупает хотя бы 6% зарегистрированных. Если платят в основном звёздами, нужно 17–28% для пакетов $5–$10 — это много; значит, при оплате звёздами пробный грант может быть в минусе, пока средний чек не вырастет до $25 и выше. Реальный расход на пробный грант почти всегда ниже максимума: обычные ответы на Free идут на бесплатный эндпоинт и ничего не списывают, платные модели расходуют кредиты только по явному выбору.

**Риск: накрутка пробных кредитов.** Каждый новый аккаунт получает 200 кредитов. Один человек с десятком адресов получит до $2.1 на модели и ничего не заплатит. Защита: вход только по коду из письма (подтверждение почты), один грант на аккаунт (`trial:${userId}`), технические лимиты Free (10 сообщений в сутки, 1 параллельный запрос), статистика регистраций в админке (`services/registration-stats.ts`). Если поток одноразовых адресов станет заметным, ограничьте регистрацию по IP или домену почты и пересчитайте окупаемость.

**Типичный пользователь.** Оценка по данным прежних подписок: активный пользователь тратил в среднем около $5.7 в месяц (с комиссией OpenRouter). Пакет $25 (11 900 кредитов) при таком расходе хватает примерно на 2 месяца: за это время мы получаем $25 и тратим ≈ $11–12, а непотраченный остаток сгорает через год.

GLM-5.3 в Auto снижает расход кредитов: средний запрос по коду обходится в ≈ 19 кредитов вместо ≈ 35. Кэш промпта снижает цену длинных диалогов (у Claude чтение кэша — 10% цены входа).

### Вывод

- **Пакеты в плюсе во всех каналах**: 33–39% маржи для карты и крипты, 10–15% для звёзд в пакетах $5–$50 и около нуля для пакета $100 в звёздах (решение владельца).
- **Для пользователя система проще и честнее**: один пул кредитов на чат, картинки и Ketner Code, цена каждого запроса видна заранее, никакой подписки и автопродления, а все модели открыты с первого дня.
- **Пробные 200 кредитов привлекают, но стоят денег**: нужны конверсия в покупку не ниже 6% (карта/крипта, пакет $10) и контроль накрутки. Следите за долей регистраций, купивших пакет, и за средним расходом пробных кредитов.
- **«Без лимита» после исчерпания кредитов — это Fair Use.** Бесплатная модель отвечает и кредитов не тратит, но на неё действуют технические лимиты уровня и общий лимит бесплатных эндпоинтов OpenRouter; в интерфейсе и на сайте так и написано («кредиты не тратятся»).
- **Админская статистика прибыльности считалась по подписке.** Метрики и оповещения в админке (`/api/admin/metrics`, `routes/admin.ts`) по-прежнему берут цену тарифа как выручку: выручка с пакетов в них не учтена, пользователи уровней Free и Credits пропускаются. Прибыль по пакетам смотрите в журнале платежей и в таблице выше; перенос метрик на пакеты — в дорожной карте.

## 4. Риски и что проверить

- **Код не проверялся на живых API**: в среде разработки нет ключей OpenRouter, Anthropic, OpenAI и Google. Перед выкладкой отправьте по 1–2 запроса на каждую модель, включая запрос с `reasoning`, Opus с кэшем промпта и GLM-5.3. Если OpenRouter отвечает 400 на значение `reasoning`, шлюз повторит запрос без параметра и напишет предупреждение в лог. Тогда поправьте таблицу размышлений модели в `model-registry.ts`.
- **Кэш промпта проверен симуляцией, а не на трафике.** Через несколько дней после выкладки откройте `/api/admin/metrics`: у Claude, GPT и Gemini `cacheStatus` должен быть `working`, а доля кэшированных токенов на длинных диалогах — десятки процентов. Если `not_working`, смотрите, что меняет префикс запроса (`ai/prompt-cache.ts`, `ai/workspace-context.ts`).
- **Прямые API.** Включайте по одному ключу и сверяйте `provider` в учёте и цены в админке со счетом вендора. Цены прямых API в реестре равны прайсу вендора на 12.10.2026; при изменении прайса поправьте `direct.pricing` через админку или в реестре. id моделей у вендоров (`claude-opus-5-5`, `gpt-6.1-sol`, `gemini-3.7-flash` и др.) тоже стоит проверить на первом запросе.
- **GLM-5.3 и границы «сложной» задачи.** Правила `AutoRouter.isHard` — эвристика по ключевым словам и длине. Проверьте на своих диалогах долю ответов GLM-5.3 и GPT-6.1 Sol в Auto и дизлайки; при необходимости расширьте список признаков или поменяйте модель (`OPEN_FLAGSHIP_MODEL_ID`).
- **Единый ключ OpenRouter — по-прежнему главная точка отказа.** При нуле на балансе (HTTP 402) отключаются все платные модели, кроме идущих через прямые API. Нужны автопополнение или оповещение при остатке ниже порога.
- **Ketner Pro — это MiMo-V2.6-Pro от Xiaomi, GLM-5.3 — модель Z.ai.** Проверьте доступность провайдеров и политику хранения данных в настройках OpenRouter.
- **Качество оценивалось по Artificial Analysis Intelligence Index**, а он измеряет общий интеллект, а не русский язык и ваши задачи. Прогоните свои типовые запросы через Ketner Pro, GLM-5.3 и Mini до запуска.
- **Учёт расхода и кредиты хранятся в Postgres** (`ketner_docs`, пространства `usage`, `credit_grants`, `premium_credits` — остатки прежних пакетов премиум-квоты) вместе с журналом платежей, поэтому остаток и гранты переживают деплой. Без `DATABASE_URL` — только в файлах `usage.json` и `credit-grants.json`, которые на Render стираются при каждом деплое.
- **Кредиты — деньги пользователя.** Списание идёт по фактической цене ответа и не больше остатка; ручная выдача и возврат оставляют след в админке (гранты `admin`, журнал платежей). Цена берётся из ответа провайдера (`usage.cost`), а если её нет — считается по таблице реестра: сверьте на живых данных сумму списаний со счётом OpenRouter.
- **Срок кредитов 365 дней и тексты условий.** Сгорание купленных кредитов и возврат в течение 14 дней описаны в оферте и условиях оплаты (`features/content/legal.ts`). Перед запуском покажите их юристу: правила о сроке действия предоплаченных средств и о возврате различаются по странам покупателей.
- **Общий лимит бесплатной модели.** Nemotron 3 Ultra и North Mini Code отвечают гостям, пользователям на пробных кредитах и покупателям без кредитов с одного аккаунта OpenRouter: 20 запросов в минуту и 1 000 в день. Если много покупателей дойдёт до нуля кредитов или поток регистраций вырастет, лимит исчерпается; смотрите долю 429 и при необходимости пополните баланс OpenRouter (лимит 1 000 в день выше при балансе от $10) или добавьте вторую бесплатную модель.
- **Ограничение частоты (RPM)** — только задержка 2 секунды, не отказ.
- **Единые цены.** Пакеты, пробный грант и срок кредитов лежат в `services/pricing.ts` и `services/entitlement.ts`; сайт читает их из `plan-facts.json`, совпадение проверяет `services/plan-facts.test.ts`. Тексты «безлимит» с сайта убраны.
- **Stripe.** Оплата картой отключена вместе с подписками: пакеты оплачиваются звёздами и криптовалютой. Переменные `STRIPE_PRICE_PLUS|PRO|ULTRA` относятся к снятым подпискам; если карту вернут, нужны цены пакетов.
- **СБП и прежние счета.** Сумма по СБП для старых подписок (890 / 2 490 / 4 890 ₽) осталась в `pricing.ts` только для счетов, выставленных до 26.10.2026; новых счетов нет. Маршрут подтверждения СБП оставлен для них же и подлежит удалению вместе с `/api/plans`.
- **Каталог `/api/plans` в `routes/billing.ts`** остаётся для счетов прежних подписчиков и обещает «контекст до 60 / 120 / 500 сообщений», а `ContextOptimizer` отправляет последние 8–13 сообщений плюс сводку. Это только текст, на расход влияет в меньшую сторону.

**Платные картинки и кредиты.** Отдельного бюджета на картинки нет: за них платят теми же кредитами, что и за чат. Если на модель не хватает кредитов, рисует запасная модель из цепочки (дешевле), а когда кредитов нет совсем — FLUX.1 schnell в пределах 5 в сутки. Одновременно у пользователя идёт одна генерация.

**Стили.** Под полем описания — «Выбрать стиль»: таблетки в одну строку со стрелками (без стиля,
рисунок на доске, аниме, промо товара, кино, мультфильм, промо приложения, комикс, UGC, затем фото,
портрет, акварель, масло, 3D, цифровой арт, пиксель-арт, скетч, неон, минимализм). Клиент присылает только id стиля, а сервер
(`images/styles.ts`) дописывает к английскому переводу фиксированную подсказку уже после проверки
запроса, поэтому через стиль нельзя обойти модерацию. Неизвестный id — без стиля.

**Модерация обязательна.** Сначала локальный фильтр (явные запросы с несовершеннолетними и
сексуальным содержанием отклоняются сразу), потом классификатор Ketner Mini через OpenRouter возвращает
`{allowed, category, prompt_en}`. Если классификатор недоступен или ответил не JSON, запрос
отклоняется. В модель уходит английский перевод описания.

**Хранение.** На Render диск временный, поэтому картинки лежат в Postgres (таблица `generated_images`,
байты в `bytea`), не больше 300 последних на пользователя. Без базы — файлы в `IMAGES_DIR`
(по умолчанию `apps/mock-api/data/images`). Файлы отдаются по подписанным ссылкам
`/api/images/:id/file?exp&sig` (HMAC, 6 часов), чтобы `<img>` работал без заголовка авторизации.

**API:** `GET /api/images/capabilities`, `GET /api/images`, `POST /api/images/generate`
`{prompt, modelId, aspect}`, `DELETE /api/images/:id`. `capabilities` отдаёт остаток кредитов и цену каждой модели. Все, кроме ссылки на файл, требуют входа.
Без `RUNWARE_API_KEY` платные модели не показываются.

**Что проверить после пополнения Runware:** по одной картинке каждой платной моделью (реальная цена
видна в учёте), и что Seedream 5.0 Flash и Nano Banana 2 принимают другие пропорции — тогда их можно
открыть в `images/models.ts`.
