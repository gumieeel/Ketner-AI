# UX-чек-лист

Паттерны, по которым прототип должен ощущаться как настоящий продукт. Отметка означает «реализовано и проверено»; для незакрытых пунктов указан этап.

## Тема и оформление

- [x] Тёмная тема по умолчанию
- [x] Переключение на светлую тему
- [x] Выбор темы сохраняется между перезагрузками
- [x] Тема применяется до первой отрисовки — нет вспышки светлого фона (инлайновый скрипт в `index.html`)
- [x] Переключатель темы доступен из шапки, сайдбара и настроек

## Адаптивность

- [x] Desktop: постоянный сайдбар шириной 288 px
- [x] Mobile: сайдбар превращается в выдвижную панель с затемнением фона
- [x] Закрытие панели по кнопке и по клавише Escape
- [x] Рабочая область занимает всю ширину и корректно скроллится независимо от сайдбара

## Экран чата (этап 2)

- [x] Ответ ассистента появляется порциями, имитируя стриминг
- [x] Индикатор «думает…» перед началом ответа
- [x] Кнопка остановки генерации во время стриминга: частичный ответ остаётся в ленте и в диалоге
- [x] Автоскролл ленты вниз при новом сообщении
- [x] Кнопка «К последнему сообщению», если пользователь пролистал ленту вверх
- [x] Рендер markdown: списки, выделение, таблицы, цитаты, разделители
- [x] Блоки кода с подсветкой синтаксиса (TS/JS, SQL, Python, shell, YAML, JSON)
- [x] Кнопка «Копировать» на блоке кода с подтверждением
- [x] Редактирование своего сообщения: лента обрезается до правки
- [x] Повторная генерация ответа
- [x] Переключатель модели в композере, выбор сохраняется
- [x] Копирование ответа целиком
- [x] Потоковые порции приходят не чаще 60 мс — интерфейс не дёргается на каждом токене

## Список диалогов (этап 2)

- [x] Кнопка «Новый чат» в шапке сайдбара
- [x] Поле поиска по чатам
- [x] Список диалогов с заголовками, сгруппированный по датам (сегодня, вчера, 7 дней, ранее)
- [x] Skeleton-состояния при загрузке истории
- [x] Переименование и удаление диалога (удаление — с подтверждением)
- [x] Автоматический заголовок диалога по первому сообщению
- [x] Подсветка активного диалога и пустой результат поиска

## Формы и валидация

- [x] Поля связаны с подписями и текстом ошибок через `aria-describedby`
- [x] Ошибка поля помечается `aria-invalid` и объявляется через `role="alert"`
- [ ] Валидация формата email и минимальной длины пароля (этап 3)
- [ ] Сообщение о неверных учётных данных (этап 3)
- [ ] Маска ввода номера карты и срока действия (этап 4)
- [ ] Экран «Подписка оформлена» (этап 4)

## Пустые и ошибочные состояния

- [x] Пустое состояние списка чатов с подсказкой
- [x] Пустое состояние чата с примерами запросов
- [x] Экран 404
- [x] Экран ошибки маршрута с кнопкой перезагрузки
- [x] Ошибка запроса к API с кнопкой «Повторить»: в ленте ответа и при загрузке истории
- [x] Ошибка «диалог не найден» отличается от сбоя связи
- [ ] Ограничение скорости или лимит плана (этап 4)

## Доступность

- [x] Все иконочные кнопки имеют `aria-label` и подсказку
- [x] Скрытый текст для декоративных иконок (`aria-hidden`)
- [x] Видимый фокус на интерактивных элементах
- [x] Контраст текста не ниже 4.5:1 в обеих темах
- [x] Сайдбар размечен как `aside` с понятным именем
- [x] Статусные сообщения объявляются через `role="status"`
- [ ] Переход к основному содержимому по Tab от начала страницы
- [ ] Проверка экранным диктором ключевых сценариев

## Локализация

- [x] Русский и английский языки интерфейса
- [x] Переключатель языка, выбор сохраняется
- [x] Ни одна пользовательская строка не захардкожена в компонентах
- [x] Словари типизированы: пропущенный ключ — ошибка компиляции
- [x] Локализация форматов дат (`Intl.DateTimeFormat` с локалью ru-RU / en-US)

## Производительность

- [x] Сборка проходит без ошибок типов, размер бандла под контролем (≈383 КБ, 117 КБ gzip; markdown — отдельным чанком)
- [x] Ленивая загрузка истории диалогов: список грузится один раз, сообщения — при открытии чата
- [ ] Виртуализация длинной ленты сообщений
- [x] Ленивое подключение тяжёлого рендера markdown (этап 2)

## Наблюдаемость

- [x] Ошибки маршрута логируются в консоль из одной точки
- [ ] Подключение Sentry — точка входа уже есть в `RouteErrorPage`
- [ ] Логирование ошибок API с идентификатором запроса
