# Дизайн-система и UX-чек-лист

## Дизайн-система «Графит и нефрит»

Действует с 12.10.2026. Токены — `apps/web/src/index.css`.

- **Цвет.** Тёмная тема по умолчанию: фон `#1A1C1B`, панели `surface-1…3`, текст `#ECEFEA`. Пастельный нефрит `#9EEFD0` — только для действий (`--action`, основная кнопка). Светлая тема: фон `#ECEEE9`, акцент текста `#0A6A4F`. Градиенты, свечение и «стекло» отключены. Цвета тарифов (`tier-plus/pro/ultra`) и вендоров моделей (`model-*`) — отдельные токены.
- **Шрифты.** Geologica Variable (у заголовков ось SHRP 100, у текста 0) и JetBrains Mono для кода; файлы WOFF2 лежат локально в `public/fonts` (латиница и кириллица, лицензия OFL).
- **Геометрия.** `corner-shape: round bevel round bevel` для всех `rounded-*`, кроме `rounded-full`: срезаны правый верхний и левый нижний углы. Работает в Chromium; Safari и Firefox показывают обычные скругления.
- **Примитивы.** `components/ui`: Button (и `buttonClasses` для ссылок), Card, Badge (в том числе тарифные), Accordion, Modal (ловушка фокуса, Escape, возврат фокуса), Tabs, Skeleton, Input; `cn()` разрешает конфликты классов Tailwind.
- **Движение.** Короткие переходы; при `prefers-reduced-motion: reduce` декоративная анимация отключается.
