# Модели, стоимость и бюджет анализа

Решения владельца от 30.10.2026 для этапа 2 [плана миграции](MIGRATION_PLAN.md). Цены — из реестра `ai/model-registry.ts` (сверены с OpenRouter 27.10.2026), плюс 5.5% комиссии пополнения OpenRouter. 1 кредит = $0.001 себестоимости. В документах и интерфейсе Discovery модели называются своими именами; служебные id каталога указаны только в разделе 7.

**Качество моделей на задачах анализа ещё не замерено** (в среде разработки нет ключей) — замер до приёмки этапа 2, раздел 6.

## 1. Модели

| Сценарий                                                               | Модель                        | Типично               | Не больше             |
| ---------------------------------------------------------------------- | ----------------------------- | --------------------- | --------------------- |
| Бесплатный анализ дня + краткий план одной возможности (платит сервис) | GPT-6 Luna (OpenAI)           | 5.6 кредита ($0.0056) | 13.9 кредита (резерв) |
| Анализ за кредиты                                                      | MiMo-V2.6 Pro (Xiaomi)        | 9 кредитов            | 27 кредитов           |
| План внедрения за кредиты                                              | MiMo-V2.6 Pro                 | 5 кредитов            | 15 кредитов           |
| «Глубокий анализ» за кредиты                                           | Claude Sonnet 5.5 (Anthropic) | 79 кредитов           | 322 кредита           |
| План к «Глубокому анализу»                                             | Claude Sonnet 5.5             | 48 кредитов           | 158 кредитов          |

Модель этапа не подменяется автоматически: если она недоступна, этап завершается понятной ошибкой с кнопкой «Повторить», а не отвечает другой, более дешёвой моделью (служебная задача идёт со `strictModel`). Бесплатная модель OpenRouter для анализов не используется: её общий лимит (1 000 запросов в сутки на весь аккаунт) нужен гостевому чату, а провайдер может сохранять запросы.

## 2. Потолок цены каждого вызова

У каждого этапа ограничены вход (системный промпт и полезная нагрузка: текст задачи до 9 000 символов, контекст и ответы до 14 000) и выход (`max_tokens`, размышления входят в него). Поэтому максимальную цену этапа сервер считает до запуска по таблице цен реестра (`discovery/model-policy.ts`), с запасом 2.2 символа на токен:

`потолок этапа = Σ по двум попыткам (токенов входа × цена входа + max_tokens × цена выхода) × 1.055`

| Этап                      | Выход, не больше                 | Попыток (повтор при невалидном JSON) |
| ------------------------- | -------------------------------- | ------------------------------------ |
| Разбор задачи             | 2 500 (Claude Sonnet 5.5: 4 000) | 2                                    |
| Поиск возможностей        | 4 000 (Claude Sonnet 5.5: 8 000) | 2                                    |
| Краткий план (бесплатный) | 2 000                            | 2                                    |
| План (за кредиты)         | 4 000 (Claude Sonnet 5.5: 6 000) | 2                                    |

Цифры в таблице раздела 1 посчитаны этим кодом по промптам на 30.10.2026. Фактическая цена берётся из ответа провайдера (`usage.cost`), так же как в чате. **С пользователя больше потолка не списывается** (`task.maxChargeUsd` в шлюзе); если провайдер вернул цену выше (например, поднял тариф), учёт пишет полную сумму — это видно при сверке цен реестра.

## 3. Бесплатный сценарий

1. Пользователь описывает задачу.
2. Ketner разбирает её и задаёт до 3 уточняющих вопросов.
3. Показывает возможности применения ИИ.
4. Пользователь выбирает одну возможность.
5. Ketner составляет краткий план внедрения именно для неё.

Создание, настройка и тестирование решения в Builder в бесплатный сценарий не входят.

### Лимиты на пользователя

| Что                                                             | Лимит                              | Как считается                                                                                                                                                     |
| --------------------------------------------------------------- | ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Бесплатный анализ                                               | 1 в сутки                          | на аккаунт; гостю — на гостевой id и отдельно на IP                                                                                                               |
| Краткий план в бесплатном анализе                               | 1 на анализ                        | для одной выбранной возможности; повторный запрос к той же возможности возвращает готовый план без вызова модели, к другой — только за кредиты                    |
| Бесплатные анализы гостей и аккаунтов младше 7 дней с одного IP | 5 в сутки                          | защита от множества аккаунтов (IPv6 — по подсети /64). Старые аккаунты не ограничиваются по IP: у мобильных операторов сотни людей выходят в сеть с одного адреса |
| Регистрации                                                     | 5 в час с IP (уже есть)            | код из письма обязателен (уже есть)                                                                                                                               |

| Анализов любого вида                                            | 20 в сутки на аккаунт              | технический лимит против злоупотреблений                                                                                                                          |

Повторная отправка запроса с тем же `Idempotency-Key` возвращает уже созданный анализ и не тратит ни лимит, ни бюджет.

### Суточный бюджет сервиса: $5

Это отдельный бюджет только на бесплатные анализы Discovery. Он не связан с расходом чата, Ketner Code, картинок и другими расходами Ketner AI и не уменьшает их лимиты.

- **Резерв до запуска.** Перед стартом бесплатного анализа сервер атомарно резервирует потолки трёх этапов: разбор $0.0040, поиск возможностей $0.0062, краткий план $0.0037 — всего $0.0139. Резерв выполняется одним SQL-запросом, который проходит, только если `потрачено + зарезервировано + новый резерв ≤ $5`. Поэтому параллельные запросы не могут вместе превысить бюджет (проверено тестом на Postgres: из 20 одновременных резервов проходит ровно столько, сколько помещается).
- **Расчёт по факту.** После этапа его резерв закрывается фактической себестоимостью из шлюза (сумма всех попыток), остаток возвращается в бюджет. Вызов, упавший до ответа провайдера (ошибка, недоступность), цены не возвращает и учитывается нулём.
- **Резервы неначатых этапов держатся 2 часа** (поиск возможностей, пока человек отвечает на вопросы, и план). Не начат за это время — резерв возвращается. Вернулся позже — сервер берёт новый резерв; не помещается — бесплатный анализ на сегодня недоступен.
- **Зависшие резервы.** Резерв этапа, который не закрылся за 15 минут (например, сервер перезапустился посреди вызова), закрывается по потолку: бюджет считается консервативно и не уходит в минус.
- **Исчерпан — новые не запускаются.** Уже начатые анализы доводятся до конца за счёт своего резерва. Новые бесплатные анализы до сброса не стартуют, на более дешёвую модель сервис не переключает.
- **Сброс** в 00:00 UTC (03:00 по Москве). Часовой пояс задаётся переменной окружения.
- **Ёмкость.** $5 — это не меньше 358 бесплатных сценариев в сутки даже при всех резервах по потолку и около 890 при типичной цене.

Что видит пользователь, когда бюджет исчерпан:

> Бесплатные анализы на сегодня закончились — их число в сутки ограничено. Новые станут доступны после 03:00 по Москве. Можно запустить анализ сейчас за кредиты: ≈ 9 кредитов, не больше 27.
>
> [Анализ за кредиты] [Напомнить завтра]

Гость вместо кнопки анализа за кредиты видит «Войти и запустить за кредиты».

## 4. Анализ за кредиты: цена до, во время и после

**До запуска** — как у моделей чата:

> Стоимость анализа: ≈ 9 кредитов, не больше 27.
> Итоговая сумма зависит от объёма анализа.
>
> [Начать анализ]

- «≈» — типичная цена по реестру; «не больше» — сумма потолков всех этапов (раздел 2). Больше потолка с пользователя не списывается.
- **Проверка баланса**: если остаток меньше потолка, анализ не запускается, и пользователь видит, сколько не хватает, и кнопку пополнения.
- **Подтверждение** нужно, если потолок операции больше 50 кредитов («Глубокий анализ»: «Не больше 322 кредитов. Запустить?»).

**Во время** каждый вызов модели идёт через существующий AI Gateway и списывается по реальной цене (`CreditService.charge`), так же как ответ в чате. Отдельного механизма списания нет.

**После** — фактическая сумма из учёта по id анализа:

> Анализ завершён. Списано: 8.7 кредита.

**При ошибке** этапы, которые не выполнялись, не списываются. Вызов, за который провайдер выставил счёт, списывается по действующей логике шлюза (так же, как ответ чата, оборванный после первых токенов); остальные этапы не запускаются. Пользователь видит, сколько списано и на каком этапе произошла ошибка, и может повторить только этот этап.

**Изменение ответов после отчёта.** Если ответы не изменились, модель не вызывается. Если изменились, поиск возможностей запускается заново: это новая генерация, поэтому она платная и у бесплатного анализа — той же моделью (у бесплатного — GPT-6 Luna, ≈ 2, не больше 7 кредитов), с ценой до запуска и явным согласием; гостю — после входа. Бюджет бесплатных анализов на это не тратится.

**Планы внедрения.** На одну возможность — один план; повторный запрос возвращает готовый план без вызова модели. Неподдерживаемой возможности (`not_supported`) план не составляется. Бесплатный анализ включает один краткий план (до 5 шагов, GPT-6 Luna) из резерва, взятого при создании анализа; если резерв истёк — берётся новый, а если бюджет исчерпан — бесплатный план недоступен. Следующие планы — подробные (до 10 шагов) и только за кредиты: у бесплатного и обычного анализа — MiMo-V2.6 Pro (≈ 5, не больше 15 кредитов), у «Глубокого анализа» — Claude Sonnet 5.5 (≈ 48, не больше 158). План за кредиты всегда запускается с явным согласием (`confirm`): без него сервер отвечает ценой, поэтому кнопка «бесплатно» никогда не приводит к списанию. Повтор упавшего плана: бесплатный — за счёт сервиса с новым резервом, платный — за кредиты. Повторный поиск возможностей заменяет возможности и удаляет планы к ним (это сказано рядом с ценой обновления); бесплатный план анализа при этом остаётся использованным.

**Помощник Builder (этап 6).** Черновик помощника из возможности — MiMo-V2.6 Pro, цена до запуска (≈ и «не больше»), только с согласием. Проверка на тест-кейсах: на каждый кейс — ответ помощника (Auto; «не больше» считается по самой дорогой модели, которую может выбрать Auto, с потолком ответа 1 500 токенов) и проверка судьёй MiMo-V2.6 Pro; цена всего прогона показывается до запуска, запуск — только с согласием. Чат помощника списывается как обычный чат, по реальной цене выбранной модели; картинки — по цене сервиса изображений.

**Повторная отправка** запроса с тем же `Idempotency-Key` (например, после обрыва сети) возвращает тот же анализ: модель не вызывается повторно, кредиты не списываются второй раз. Этап в статусе «выполняется» или «готово» повторно не запускается.

## 6. До приёмки этапа 2

1. **Замер качества**: 20 типовых описаний задач на русском (работа, бизнес, учёба, контент, код) через GPT-6 Luna, Claude Haiku 5.5, Qwen3.8 Flash и MiMo-V2.6 Pro. Метрики — доля валидного JSON с первой попытки, доля возможностей, привязанных к контексту пользователя, ручная оценка полезности. Нужен ключ OpenRouter в среде разработки или staging. Если GPT-6 Luna не проходит, выбор бесплатной модели пересогласуется.
2. **Сверка цены**: после первых настоящих анализов сравнить себестоимость из учёта с расчётом и со счётом OpenRouter.

## 7. Для разработчиков

- Служебные id моделей в реестре: GPT-6 Luna — `ketner-mini`, MiMo-V2.6 Pro — `ketner-pro`, Claude Sonnet 5.5 — `claude-sonnet-5.5`. В интерфейсе Discovery показывается настоящее имя модели (`ai/model-disclosure.ts`).
- Настройки: `DISCOVERY_FREE_DAILY_USD` (по умолчанию 5), `DISCOVERY_BUDGET_TZ` (по умолчанию `UTC`).
- Числа задачи (сколько раз в неделю, сколько минут) попадают в расчёт пользы, только если модель привела дословную цитату из описания пользователя с этими числами и сервер нашёл её в тексте (`discovery/impact.ts: verifyTaskNumbers`). Иначе польза описывается словами. Это строгое правило: пересчитанные моделью числа («2–3 часа в день» → «10 раз в неделю по 15 минут») тоже отбрасываются.
- Таблицы бюджета создаёт миграция `0001_discovery`: `discovery_budget_days` (сутки, лимит, потрачено, зарезервировано) и `discovery_budget_reservations` (резерв, этап, анализ, потолок, факт, статус, срок).
