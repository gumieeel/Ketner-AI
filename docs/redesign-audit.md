# Ketner AI: аудит фронтенда (шаг 1)

Аудит статический: сделан по исходникам `apps/web/src`. Скриншоты в светлой и тёмной теме на 375, 768 и 1440 px не снимались, потому что в облачном окружении нет доступа к npm (`registry.npmjs.org` заблокирован), а значит нет сборки, typecheck, vitest и Playwright. После открытия сети этот документ нужно дополнить скриншотами.

## Что уже хорошо

- Токены вынесены в `index.css` (`:root`, `.dark`, `@theme inline`), на них опираются все компоненты. Тест `tokens.test.ts` страхует состав токенов, поэтому имена токенов не меняем.
- Примитивы `components/ui/*` имеют единый API (`Button`, `Card`, `Badge`, `Input`, `Tabs`, `Tooltip`, `Skeleton`), у `Tabs` и `Tooltip` есть клавиатура и aria.
- Тема переключается до первой отрисовки (скрипт в `index.html`), мигания нет.
- Есть блок `prefers-reduced-motion`.

## Ограничения, которые не нарушаем

- `apps/mock-api` не трогаем. В `apps/web` не меняем `features/*`, сторы, api, роутинг и поведение.
- Имена токенов остаются, все `REQUIRED_TOKENS` лежат в первом блоке `:root{…}` и первом `.dark{…}`, без вложенных скобок.
- Тексты в мобильном меню и кнопки «Открыть меню» и «Закрыть меню» остаются, на них опираются тесты.

## Порядок работ

1. Токены и анимации в `index.css`, шрифт Onest.
2. Примитивы `components/ui/*`.
3. Лендинг.
4. Чат, включая выбор модели в шапке.
5. Тарифы, оплата, вход и регистрация, настройки, документация.
6. Пустые, загрузочные и ошибочные состояния, страница 404.

После каждого шага: `npm run typecheck --workspace @ketner/web` и `npm test --workspace @ketner/web`, затем атомарный коммит.
