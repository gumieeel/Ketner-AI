# План: автоматизации для людей без опыта с ИИ

Составлен 01.11.2026 по решениям владельца; продуктовая часть и расчёт цены — в документе «Ketner AI — план продукта для обычных людей» (Claude Docs). Продолжает [MIGRATION_PLAN.md](MIGRATION_PLAN.md): платформа решений уже включена в production ([ACCEPTANCE.md](ACCEPTANCE.md)).

## 1. Цель

Человек пишет пару слов о своём деле или вставляет ссылку, через минуту видит, что ИИ возьмёт на себя, и одной кнопкой «Приступить к автоматизации» запускает готовую автоматизацию. Первая автоматизация — бот для клиентов, который живёт на сайте Ketner. Запуск автоматизаций — по подписке $15 в месяц (7 500 кредитов) с пробным месяцем по карте.

## 2. Решения владельца (01.11.2026)

1. Рынок — весь мир; приём карт через сервис-посредник Dodo Payments (решение 01.11.2026 вместо Paddle), для России остаются Stars и крипта.
2. Цена считается от расхода моделей на автоматизации: подписка $15 = 7 500 кредитов в месяц, пробный месяц — 2 000 кредитов.
3. Первая автоматизация — бот для клиентов прямо на сайте Ketner, не в Telegram; в профиле раздел «Мои автоматизации» с созданными ботами.
4. Карта — сразу при нажатии «Приступить к автоматизации».
5. Агрегатор (чат с моделями) остаётся отдельным разделом; кредиты видны везде.
6. Названия моделей в анализе — в «Подробнее»: людям без интереса к моделям они не нужны.
7. Анализ идёт по плану: всегда проверяет одни и те же области и сводит находки к готовым рецептам.

## 4. Критерии готовности

| Этап | Готово, когда                                                                                                                                                                                                                                                        |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A    | В отчёте видно, какие области проверены и что найдено; у каждой возможности есть область; рецепт — только из доступных; не меньше 3 возможностей (иначе повтор запроса); вопрос — не больше одного; ссылка на сайт читается сервером с защитой от внутренних адресов |
| B    | Клиент без входа пишет боту на его странице и получает ответ; владелец видит диалоги и заявки; расход списывается с владельца; при нехватке кредитов бот собирает заявки, а не молчит; чужой бот недоступен для изменения                                            |
| C    | Баланс виден на всех страницах; перед каждым платным действием показана цена                                                                                                                                                                                         |
| D    | Новый человек входит через Google без пароля и кода                                                                                                                                                                                                                  |
| E    | Тестовая карта в тестовом режиме Dodo Payments: пробный месяц, списание, отмена, повторный вебхук не начисляет кредиты дважды                                                                                                                                        |
| F    | Подборка приходит по расписанию и списывает кредиты по факту                                                                                                                                                                                                         |

Правила прежние: без имитации функциональности, миграции для изменений базы, проверки доступа на сервере, идемпотентность платежей, тесты не объявляются пройденными без запуска.

## 5. Бот для клиентов (этап B, как сделано)

- Бот — решение Builder с типом `customer_bot`: поведение (знания, тон, запреты, примеры) хранится версиями и проверяется тест-кейсами, как у помощника; включается только проверенная версия.
- Черновик из рецепта `customer_bot` пишет модель по описанию, ответам и тексту прочитанного сайта: знания — только факты оттуда, приветствие, 3–4 кнопки, тест-кейсы с вопросом, ответа на который нет.
- Страница `ketner.org/b/<адрес>` без входа; на свой сайт — одна строка `<script src="https://ketner.org/widget.js" data-bot="<адрес>" async>`. Страница бота встраивается в любые сайты (`frame-ancestors *` только для `/b/<адрес>`), ссылок внутрь Ketner на ней нет.
- Промпт бота заменяет правила чата Ketner (`replaceSystemPrompt`): только тема бизнеса, факты только из знаний и исправленных ответов, не знает — метка `[[CONTACT]]`, и сервер показывает клиенту форму заявки. Данные владельца и сообщения клиента — данные, не инструкции.
- Платит владелец: модель Auto, не больше 30 кредитов за ответ, суточный потолок (по умолчанию 1 000 кредитов). Потолок достигнут или баланс пуст — бот без вызова модели предлагает оставить контакт. Заявки бесплатны, приходят в кабинет и письмом; оставить заявку можно и у выключенного бота.
- Лимиты: 20 сообщений за 10 минут на посетителя, 60 на адрес, 5 заявок в час с адреса. Посетитель — случайный `v_…` в его браузере; чужой диалог по id не открывается.
- Кабинет: ссылка, QR-код, код для сайта, расход за сегодня, проба «как клиент» (текущая версия, ничего не сохраняется), заявки, диалоги и «Исправить ответ» — исправление сразу попадает в промпт без новой версии.

## 6. Оплата через Dodo Payments (этап E, подготовка)

Dodo Payments — сервис-посредник (продавец для покупателя — Dodo: налоги с продаж и возвраты на нём), принимает карты по всему миру.

- Комиссия (страница цен на 01.11.2026): 4% + $0,40, ещё +1,5% за карту не из США и +0,5% за подписку. С подписки $15 картой не из США — около $1,30 (8,7%), Ketner получает ≈ $13,70. Вывод денег — бесплатно, но меньше $1 000 — $5, перевод SWIFT в долларах — $25.
- Пробный период: `subscription_data.trial_period_days` в сессии оплаты — карта сохраняется сразу, первое списание в конце пробного периода; подписка в пробном периоде имеет статус `active`.
- Вебхуки (Standard Webhooks, подпись проверяется): `subscription.active`, `subscription.renewed` — начислить 7 500 кредитов за период (идемпотентно по id платежа/периода), `subscription.on_hold`, `subscription.cancelled`, `subscription.expired` — остановить начисление; `payment.succeeded`/`payment.failed`.
- Продавец: можно зарегистрироваться как физлицо (Individual) без компании: документ с фото и селфи (Persona), банковский счёт на то же имя. Казахстан — в списке стран продавцов. Минимальный возраст в правилах не указан; договор и выплаты — на владельца аккаунта, поэтому аккаунт открывает совершеннолетний (родитель) или нужно письменно уточнить у Dodo (support@dodopayments.com).
- Что спросить у compliance@dodopayments.com до запуска: правила запрещают «перепродажу AI API без прав» и хранимую стоимость (кошельки). Подписка на автоматизации с кредитами внутри продукта, по правилам, не описана — нужен письменный ответ, что модель Ketner (подписка → кредиты на ботов и анализы, агрегатор моделей через OpenRouter) допустима.
- На сайте до подключения должны быть: цены, условия, политика конфиденциальности, правила возврата и отмены, контакты — у Ketner они есть.
- Ключи: `DODO_PAYMENTS_API_KEY`, `DODO_PAYMENTS_WEBHOOK_KEY`, режим `test_mode`/`live_mode`; без ключей кнопка оплаты честно недоступна.

## 7. Кредиты на виду (этап C, как сделано)

- Остаток в шапке на всех страницах после входа (и в боковой панели чата): число со значком, ведёт на «Кредиты»; на исходе или закончились — предупреждающий цвет. Обновляется при открытии страницы и возврате на вкладку (не чаще раза в 30 секунд) и после каждого ответа в чате.
- У бота и в «Моих автоматизациях»: остаток и «хватит примерно на N дн.» — остаток делится на средний расход всех ботов владельца за 7 дней (или за срок жизни, если ботам меньше недели); при ≤ 3 днях — подсветка и кнопка «Пополнить».
- Цена до платного действия уже была: анализ, планы, черновик, проверка на тест-кейсах, проба бота (до 30 кредитов за ответ), ответ в чате.
- Письмо «Кредиты на исходе» (`services/low-credits-notifier.ts`): после списания, когда остаток ≤ 20% выданного действующими грантами; один раз на набор грантов (после пополнения — снова), отметка в `ketner_docs` (`low_credit_notices`), не уходит на служебные адреса Telegram и при выключенных напоминаниях; не отправилось — попытка при следующем списании.

## 8. Вход и подписка (этапы D и E, состояние на 01.11.2026)

- D: вход через Google уже работает на ketner.org (Better Auth, кнопка первой на страницах входа и регистрации), возврат на страницу анализа после входа, анализ гостя этого браузера переходит в аккаунт при открытии. Отдельной работы не потребовалось.
- E, код: `billing/automation-subscription.ts`, `routes/automation.ts` (SDK `dodopayments` 2.55.0). Сессия оплаты с `trial_period_days: 30` (один раз на аккаунт) и `metadata.ketner_user_id`; вебхук `/api/webhooks/dodo` проверяет подпись SDK на сыром теле, обрабатывает событие один раз по `webhook-id`; `subscription.active` в пробном месяце — 2 000 кредитов (`dodo:<подписка>:trial`), оплаченный период (`subscription.active`/`renewed`) — 7 500 кредитов (`dodo:<подписка>:<начало периода>`), до следующей даты списания; статусы `on_hold`, `cancelled`, `expired` и др. сохраняются. Напоминание за 3 дня до конца пробного месяца — письмом раз в час по таймеру. Портал клиента Dodo — отмена в одно нажатие. Карточка на «Кредитах» и предложение в отчёте при `402 subscription_required` — только когда оплата картой подключена (метка `card-payments`).
- E, чтобы включить: аккаунт продавца в Dodo (совершеннолетний владелец), продукт-подписка $15/мес в кабинете Dodo, вебхук на `https://ketner.org/api/webhooks/dodo`, переменные из docs/environment.md; проверить тестовой картой в `test_mode` (пробный месяц, продление, отмена, повтор вебхука), потом `live_mode` и `AUTOMATION_SUBSCRIPTION_REQUIRED=1`.
