# Telegram

Два бота и мини-приложение. Код — `apps/mock-api/src/telegram/`, маршруты — `routes/telegram*.ts`, страница кабинета — `apps/web/src/pages/telegram-app-page.tsx`.

## Бот оплаты и кабинета (`@Robo_kassa_bot`)

- Кнопка меню «Кабинет» открывает мини-приложение `https://ketner.org/tg`; ссылки бота ведут сразу на вкладку: `/tg?tab=plans|payments|profile|admin`.
- Команды: `/start` (меню, тарифы), `/status` (срок тарифа), `/paysupport` (возвраты и вопросы по оплате), `/terms` (условия). Для администраторов: `/clearpayments @username` — удалить историю оплат, `/resetplan @username` — обнулить тариф (с подтверждением).
- Deep-link параметры `/start`: `auth_…` — подтверждение входа на сайт, `lnk_…` — привязка аккаунта, `stars_…` — открыть счёт в звёздах.
- Работает через вебхук `POST /api/telegram/webhook`, который бот сам регистрирует при старте с секретом в заголовке `X-Telegram-Bot-Api-Secret-Token` (секрет выводится из `BETTER_AUTH_SECRET`). Локально, без https-адреса, — long polling.

### Кабинет `/tg`

Вкладки: **Главная** (срок, автопродление, быстрые действия), **Тарифы** («На 30 дней» и «С автопродлением», итоговая дата и пересчёт при смене тарифа), **Платежи** (история, чек, заявка на возврат), **Профиль** (вход на сайт одной кнопкой, уведомления, язык, поддержка, отвязка), **Возвраты** — только администраторам.

Данные мини-приложения проверяются по подписи Telegram `initData` (`telegram/webapp-auth.ts`).

## Аккаунты и Telegram

**Аккаунты через Telegram не создаются**: регистрация — только на сайте. Telegram привязывается к существующему аккаунту одним из способов:

| Способ            | Как                                                                                                      |
| ----------------- | -------------------------------------------------------------------------------------------------------- |
| Код из письма     | В кабинете ввести почту аккаунта → код на почту → ввести код (нужен SMTP)                                |
| Почта и пароль    | В кабинете ввести почту и пароль аккаунта (лимит попыток)                                                |
| Из настроек сайта | Настройки → Telegram → «Подключить Telegram»; бот просит подтвердить                                     |
| Код для сайта     | Кабинет выдаёт код (6 символов, 10 минут) — ввести на сайте; для тех, кто входит через Google или GitHub |

Один Telegram — один аккаунт: новая привязка снимает старую. Аккаунты, созданные через Telegram раньше (служебная почта `tg-<id>@telegram.invalid`), продолжают входить как прежде и не могут отвязать Telegram — это их единственный вход.

### Вход на сайт через Telegram

Кнопка «Войти через Telegram» на `/login` и `/signup`: сайт создаёт запрос (`POST /api/auth/telegram/start`), показывает кнопку «Открыть Telegram» и QR, бот присылает сообщение с устройством, с которого начат вход, и кнопками «Войти» / «Это не я»; страница опрашивает `GET /api/auth/telegram/poll/:id` и входит сама. Запрос живёт 5 минут, сессия выдаётся один раз. Непривязанный Telegram войти не может.

Из кабинета можно войти на сайт одноразовой ссылкой `/auth/telegram?t=…` (2 минуты, один раз, `POST /api/auth/telegram/magic`).

Остаточный риск: это device-flow, поэтому злоумышленник может прислать жертве ссылку на подтверждение своего входа. Бот предупреждает об этом и показывает устройство.

## Бот поддержки (`@ketner_support_bot`)

- Пользователи пишут обращения; они сохраняются как тикеты (`store/support-store.ts`, зеркало в Postgres) и пересылаются оператору.
- Все уведомления администратору приходят сюда: новые оплаты (в том числе бесплатные выдачи Pro), заявки на возврат с кнопками, сообщения с формы `/contacts`. Если бот поддержки не настроен, бот оплаты пишет администраторам с привязанным Telegram.
- Оператор определяется по `SUPPORT_ADMIN_CHAT_ID` (надёжно) или `SUPPORT_ADMIN_USERNAME` (username можно сменить, поэтому задайте chat id).
- Вебхук `POST /api/telegram/support/webhook` с отдельным секретом.

## Настройка

1. Токены от @BotFather → `TELEGRAM_BOT_TOKEN`, `TELEGRAM_SUPPORT_BOT_TOKEN` на Render ([environment.md](environment.md#telegram)).
2. BotFather → Bot Settings → Configure Mini App → `https://ketner.org/tg` (необязательно: кнопка меню бот ставит сам).
3. Чтобы администратор получал заявки и мог одобрять возвраты, его аккаунт сайта должен быть администратором (`ADMIN_EMAILS` или флаг в админке) и привязан к Telegram.
4. После смены токена бота вебхук переустановится при следующем старте сервера.

Временная выдача Pro без оплаты в мини-приложении описана в [payments.md](payments.md#временно-бесплатный-pro-в-telegram).
