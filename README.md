# Ketner AI

Кликабельный прототип веб-продукта в жанре AI-чата: интерфейс и UX воспроизводят поведение ChatGPT, но под капотом работают заглушки — без реального LLM, реальной авторизации и реальной оплаты.

Цель — показать инвесторам и пользователям полноценно работающий продукт и при этом заложить архитектуру так, чтобы заглушки позже заменились на реальные сервисы без переписывания фронтенда.

> **Live Demo**: [https://ketner-ai.onrender.com](https://ketner-ai.onrender.com) — единый сервис фронтенда и mock-API на Render.

## Как устроена заглушка

Диалоги и сообщения хранит mock-API: диалог создаётся при отправке первого сообщения, а при каждом запросе на сервер уходит вся история. Поэтому правка сообщения, повторная генерация и остановка работают без отдельных эндпоинтов — сервер принимает новую историю и заменяет ею сохранённую.

Ответ «модели» собирается из шаблонов по ключевым словам запроса и отдаётся потоком SSE: пауза 350–900 мс перед первым чанком (в интерфейсе видно «думает…»), затем порции текста каждые 20–40 мс. Задержки, доля сбоев и файл хранилища настраиваются переменными `MOCK_AI_*` и `STORE_FILE`.

## Требования

- Node.js 20 или новее (разрабатывалось на 24.21)
- npm 10 или новее

## Установка и запуск

```bash
npm install
npm run dev
```

Поднимутся два процесса:

- фронтенд — http://localhost:5173
- mock-API — http://127.0.0.1:8787, описание контракта на http://127.0.0.1:8787/api

Приложение открывается на http://localhost:5173. Порт mock-API (`8787`) обслуживает только `/api/*`: если открыть его в браузере, корень объяснит это и подскажет адрес интерфейса.

Запросы с фронтенда на `/api/*` проксируются на mock-API (настройка в `apps/web/vite.config.ts`), поэтому CORS в разработке не мешает.

Запуск по отдельности:

```bash
npm run dev:web
npm run dev:api
```

## Переменные окружения

Для прототипа обязательных переменных нет. Настройки mock-API перечислены в `apps/mock-api/.env.example`:

| Переменная              | Назначение                                         | Значение по умолчанию           |
| ----------------------- | -------------------------------------------------- | ------------------------------- |
| `PORT`                  | Порт mock-API                                      | `8787`                          |
| `NODE_ENV`              | Окружение                                          | `development`                   |
| `CORS_ORIGIN`           | Разрешённый origin                                 | `http://localhost:5173`         |
| `WEB_APP_URL`           | Адрес интерфейса в подсказке на `GET /`            | `http://localhost:5173`         |
| `STORE_FILE`            | Файл с диалогами и сообщениями                     | `apps/mock-api/data/store.json` |
| `MOCK_AI_THINKING_*_MS` | Пауза перед первым чанком (индикатор «думает…»)    | `350` / `900`                   |
| `MOCK_AI_CHUNK_*_MS`    | Пауза между порциями текста                        | `20` / `40`                     |
| `MOCK_AI_FAILURE_RATE`  | Доля запросов, завершающихся ошибкой (0 — никогда) | `0`                             |

Переменные, которые появятся на следующих этапах, перечислены в соответствующих документах: `AI_API_KEY`, `AUTH_*`, `PAYMENT_*`.

## Процесс работы

Разработка идёт этапами: после каждого этапа — остановка и подтверждение. Изменения коммитятся и пушатся напрямую в `main`; перед каждым коммитом прогоняются линтер, проверка типов, тесты и форматирование.
